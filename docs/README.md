## 目录职责

- `product/`：当前 PRD、范围、需求和验收标准；
- `technical/`：技术验证、架构决策和切片结论；
- `design/`：当前原型规范、状态矩阵和设计约束；
- `research/`：竞品、用户研究、可用性测试和效果研究；
- `archive/`：被新版规格取代但需要保留的历史材料。

## 文档状态约定

文档顶部应声明：

- 版本和日期；
- 状态：草稿、待评审、已确认、已归档；
- 适用范围；
- 替代或依赖的文档；
- 未验证假设。

归档文档不得继续作为实现依据。若归档观点重新启用，应在当前 PRD 或技术决策中重新确认。
