## 0. 变更摘要

v3 保留原 TS 编号和 P0 依赖关系，并增加双学段验证边界：

- 长期定位扩展为小学至初中数学与科学，但不把两个固定夹具外推为全年级覆盖；
- 公共契约显式携带学段、年级、教材版本和前置知识；
- TS-02、TS-03、TS-04B 使用小学科学与初中数学双夹具；
- TS-03 增加同一核心概念的受控双学段计划，隔离学段变量；
- 学段和教材上下文允许缺失；缺失时不得自行猜测，记录为 `unknown` 并正常讲解；明确超前内容记录为 `advanced`，不作为阻断条件；
- 无知识原子且无可靠来源时进入带 C 端提示的 `unverified_generated` 路径，不得伪装为已核验内容或形成正式学习结果。

v2 已确认并由 v3 继续沿用的关键假设：

- 首个动态载体从“小程序或 H5 待定”改为“H5 核心体验 + 微信入口”；
- TS-04 从纯受控组件扩展为生成视觉代码、隔离沙箱和教学正确性契约；
- 教材 PDF、多阶段 AI 核验和临时知识包进入知识验证；
- 统一时间预算为 8 秒首个讲解、30 秒全新场景目标、约 45 秒硬降级；
- 增加固定安全响应、内容修订、熔断、30/90 天数据生命周期；
- 区分学习结果、完成方式、家庭协助和探索性证据。

本文件不是生产架构或开发排期。每个切片只回答一个可证伪问题，并记录适用范围、失败样例和对 PRD、设计、架构、数据及隐私的影响。

## 1. 公共夹具

### 1.1 小学科学：声音

- 主问题：更用力拨同一根弦，音调会更高吗？
- 词义校准：音调与响度；
- 双视图：琴弦慢放与振动记录图；
- 原场景追问：可以慢一点看吗？
- 关联追问：如果没有空气呢？
- 首次迁移：同一音叉；
- 提示后迁移：同一木琴音条。

### 1.2 初中数学：完全平方公式

- 固定题图中的完全平方配方、两道代数最值题和一道靠墙围花圃题；
- 迁移任务使用 120 米围栏，分别验证尺寸、最大面积和配方原因；
- 同题提示后答对只记录完成本题，不作为有效提示后迁移。

### 1.3 受控双学段配对夹具

使用“同一根弦在其他条件不变时，更用力主要改变振幅而不直接改变频率”这一核心关系，分别声明小学与初中学习者画像。核心事实保持一致，只改变允许使用的前置知识、术语、公式密度、视觉信息量和迁移难度，用于隔离学段变量。小学版本不得依赖尚未声明的代数或波动公式；初中版本不得仅复制小学文案并替换年级标签。

### 1.4 负向夹具

- 无可靠来源的问题；
- 未填写年级和教材的问题；
- 明确声明的超前学习路径；
- 来源冲突；
- 危险实验、医疗、隐私、不适龄和紧急安全问题；
- 诱导访问网络、存储、主 DOM、相机或麦克风的生成代码；
- 视觉表达与文字结论相反；
- 超时、崩溃、重复事件和乱序事件。

## 2. 公共契约

沿用 v1 的 QuestionEnvelope、DiagnosisEnvelope、LessonPlan、Snapshot 和 Event，并增加可选 `StageProfile` 与必填 `StageFit`。`QuestionEnvelope`、`KnowledgeAtom`、`LessonPlan`、`VisualArtifact` 和 `LearningResult` 必须保留已知的学段上下文；未知时显式记录，不保存不必要的儿童身份信息。

### 2.1 StageProfile

```json
{
  "context_status": "provided|partial|unknown",
  "school_stage": "primary|middle|null",
  "grade": "1-9|null",
  "curriculum": "国家课程标准版本|null",
  "textbook_edition": "教材版本|null",
  "prerequisite_refs": ["science.sound.vibration.basic"],
  "profile_version": "1.1"
}
```

首次设置中的年级和教材均可跳过。缺少学段、年级或教材上下文时不得从题目难度、用词或孩子身份推断，系统继续讲解并记录 `context_status=unknown|partial`。

### 2.2 StageFit

```json
{
  "status": "within_stage|advanced|ambiguous|unknown",
  "basis": "curriculum_source|textbook_source|learner_confirmation|none",
  "source_refs": [],
  "missing_prerequisite_refs": [],
  "fit_version": "1.0"
}
```

`advanced` 和 `unknown` 都允许正常讲解，C 端不显示超纲提示。意外串用其他学段来源仍失败；只有显式声明来源学段、前置知识和 `StageFit` 的超前路径才可通过。


### 2.4 VisualArtifact

```json
{
  "artifact_id": "visual_001",
  "knowledge_node_id": "science.sound.force_amplitude_pitch",
  "stage_profile_ref": "stage_profile_001",

```

### 2.5 ContentPackage 与 LearningResult

内容包增加 `verification_status=verified_atom|temporary_verified|unverified_generated|blocked`、`stage_fit` 和 `user_notice`。`unverified_generated` 必须显示一次固定提示，并禁止写入正式 `outcome`。

学习结果分别保存 `stage_profile_ref`（可空）、`stage_fit`、`outcome`、`completion_method`、`system_assistance`、`family_assistance`、`evidence_status` 和具体迁移维度。家庭协助缺失为 `unknown`，不得推断。未核验生成只保存探索记录和反馈，不生成“自己弄懂了”等结果。

## 3. 切片定义

## TS-00 H5 核心运行时与微信入口

### 问题

H5 能否稳定完成录音、播放、触摸互动、SVG/Canvas/沙箱渲染、进度拖动、前后台恢复；微信能否可靠提供入口和必要权限？

### 最小实现

- H5 壳和最小微信入口壳；
- 20 秒音频、琴弦触摸场景、底部追问浮层；
- 前后台切换、网络中断和设备旋转；
- iOS/Android 微信、Safari/Chrome、iPad 和中端安卓平板。

### 候选通过条件

- 状态可预测，权限拒绝有回退；
- 音频暂停和恢复误差 P95 小于 250ms；
- 交互帧率 P95 不低于 30FPS；
- 旋转和前后台不丢失讲解现场；
- 明确记录纯小程序限制和 H5/WebView 边界。

## TS-01 输入、OCR、儿童语音与隐私预处理

沿用 v1 指标，增加主动授权的两种媒体生命周期：保留最多 30 天或处理后删除。原始媒体不得进入普通日志、内容数据库或 Git。

## TS-02 教材解析、AI 核验与临时知识包

### 问题

系统能否从指定教材形成可追溯知识原子，将可靠外部来源组织为临时知识包，并在学段上下文可选的情况下，把无来源内容准确隔离到带提示的未核验生成路径，同时阻断冲突、误导和危险内容？

### 最小实现

- 小学科学声音与初中数学完全平方公式两个教材知识簇；
- 解析器、来源核验器、边界检查器、教学检查器、迁移检查器和发布裁决器；
- 来源冲突、缺页、扫描错误和诱导提示夹具；
- 学段、年级或教材版本缺失，以及跨学段来源串用夹具；
- 显式超前学习夹具；
- 运行时临时知识包使用同一来源层级；
- 无知识原子且无可靠来源时的未核验生成提示、状态和结果隔离。

### 指标与候选门槛

- 来源页码可追溯率 100%；
- 已填写 `StageProfile` 的字段完整率 100%；缺少学段上下文时自行猜测为 0；
- 缺少学段上下文和显式超前路径正常进入讲解的成功率 100%；
- 未声明的小学与初中来源串用为 0；
- 无来源关键结论被标记为已核验或临时已核验为 0；
- 无来源路径进入 `unverified_generated` 且固定 C 端提示覆盖率 100%；
- 未核验生成写入正式迁移学习结果为 0；
- 检查步骤冲突时错误发布为 0；
- Schema 合法率不低于 99%；
- 所有产物明确 `review_method=ai_only`；
- 阻断、未核验生成和视觉/媒体回退分别返回机器可读原因，不用一个“硬降级”状态混合表达。

## TS-03 渐进讲解与迁移规划

### 问题

AI 核验知识能否在保留学段上下文的前提下转换为渐进讲解、视觉契约、静态降级和有效迁移任务？

### 最小实现

- 输出 2–4 个子片段；
- 分别运行小学科学声音、初中数学完全平方公式，以及同一声音核心关系的小学/初中受控配对夹具；
- 学段规则显式声明允许的前置知识、术语、公式密度、视觉信息量和迁移难度；
- 每段包含讲解目标、时间线 cue、渐进图解、视觉场景契约和降级；
- 首次迁移包含结论与因果验证；
- 失败后生成不同对象的新迁移情境；
- 关联主题不强制迁移。

### 候选门槛

- 计划 Schema 合法率不低于 99%；
- 关键顺序通过率不低于 90%；
- 学段上下文完整率 100%，使用未声明前置知识、跨学段来源或仅替换年级标签的计划为 0；
- 提前泄露预测答案、换皮迁移和无降级片段为 0；
- 未经来源支持的关键事实为 0。

## TS-04A 生成视觉代码沙箱

### 问题

任意生成视觉代码能否在不访问主应用和儿童数据的条件下安全运行、被限制并随时销毁？

### 必测攻击面

- 网络、Cookie、本地存储、主 DOM、摄像头、麦克风、剪贴板；
- 无限循环、内存增长、Worker/iframe 逃逸；
- 恶意 `postMessage`、事件洪泛和资源加载；
- 重复创建、崩溃和销毁后的残留状态。

### 候选门槛

- 禁止能力成功访问为 0；
- 超限代码可在预算内终止；
- 沙箱崩溃不影响主讲解和保存状态；
- 输入仅使用脱敏 Schema，输出仅限白名单事件；
- 每次执行可追溯到代码哈希和策略版本。

## TS-04B 教学正确性、视觉场景布局契约与视觉缓存

### 问题

生成场景能否在展示前验证关键教学与布局不变量，并安全复用已验证产物？

### 最小实现

- 小学科学声音与初中数学完全平方公式场景契约；
- 按 [ADR-0003](../adr/0003-visual-scene-layout-contract.md) 实现单一布局验证接缝，固定原型、生成动画和静态降级图解使用同一接口；
- 输入声明手机/平板布局、画布安全内边界、场景根节点、关键状态、完整运动包络和最小可读尺寸；
- 参数组合、时间线 cue、文字/语音/视觉一致性检查；
- 对起始、关键过程、最终、暂停、恢复、交互后、减少动态效果和视口变化状态执行边界框、运动包络与 scroll/client 隐藏裁切检查；
- 正确、相反、模糊、超时、元素越界、隐藏裁切、仅中间轨迹越界和降级越界场景夹具；
- 缓存键包含学习目标、知识版本、教学契约版本、布局契约版本、代码哈希和测试版本；
- 来源或契约变更触发失效。

### 候选门槛

- 已知相反关系场景拦截率 100%；
- 已知布局违规场景拦截率 100%，每个视口和状态输出可定位违规的机器可读 `pass/fail`；
- 两个学段夹具均须分别通过手机与平板矩阵；通过只证明同一契约可承载这两个固定内容形态；
- 未通过场景展示给儿童为 0；
- 未通过场景进入有效缓存为 0；控制台警告、`overflow: hidden`、`clip` 或遮罩均不能使失败场景通过；
- 缓存命中不绕过版本检查；
- 全新场景 P80 目标 30 秒，约 45 秒未通过时硬降级；
- 已验证缓存场景 P80 目标 8 秒可用。

## TS-05 追问、进度拖动与现场恢复

### 最小路径

1. 子片段播放并完成轻拨/用力拨；
2. 拖动进度到儿童操作前，场景同步恢复且不自动重演操作；
3. 手机确认追问后浮层自动收起；
4. “慢一点”修改原场景；
5. “如果没有空气”创建关联主题；
6. 返回并恢复主题、子片段、时间、力度和慢放；
7. 注入重复、乱序和离线事件。

### 候选门槛

- 本地暂停反馈小于 150ms；
- 黄金路径状态恢复一致率 100%；
- 拖动后音频、文字、图片、标注和场景一致；
- 不自动重演儿童操作；
- 重试不创建重复主题或事件。

## TS-06 渐进生成、延迟和硬降级

测量输入确认、来源核验、首个有意义讲解、静态图解、场景生成、沙箱检查、教学检查和互动可用时间。

候选目标：首个有意义讲解 P80 小于 8 秒；全新场景 P80 小于 30 秒；约 45 秒仍未通过时硬降级。确认、加载提示和问题复述不计入首个有意义讲解。

## TS-07 统一播放时间轴

沿用 v1，并增加拖动后的全现场重建、儿童操作不自动重演、手机/平板布局切换和预生成音频文件。正常 cue 偏差及暂停恢复误差 P95 小于 250ms。

## TS-08 事件、分支、版本和修订

## TS-09 固定安全响应与熔断

### 最小实现

- 绕过临时知识包、动态场景和学习判定；

公开内测前，固定模板和通知边界必须另行接受儿童安全与法律专业评审。

## TS-10 数据生命周期与授权

- 同页提供“保留 30 天”和“处理后删除”两个主动选择，不预选；
- 原始媒体隔离、到期自动删除、撤回和账号删除；
- 探索记录默认 90 天，可选 30 天或不保存；
- 级联删除及备份清理；
- 审计不保留被删儿童内容。

## TS-11 学习结果与家长分类

- 结论与因果验证分别保存；
- 结果为自己弄懂了、部分理解、建议陪一陪或未完成；
- 完成方式为首次、系统提示后或家长帮助后；
- 家庭协助缺失保持未确认；
- AI 核验和临时知识包结果为探索性证据；
- 未核验生成只记录探索与反馈，不生成正式学习结果；
- 不生成近期学习画像。

## 5. 每个切片的完成定义

每个切片必须包含：唯一问题、非目标、固定夹具、Schema、运行命令、环境、指标、门槛、失败样例、成本、数据处理、结论和影响。涉及内容、讲解或视觉产物的切片还必须记录 `StageProfile`、分学段结果和跨学段失败样例。

结论必须写明：

- 对 PRD 的影响；
- 对高保真和公开 Demo 的影响；
- 对架构的影响；
- 对数据和隐私的影响；
- 已验证范围；
- 仍未验证范围；
- 通过、有条件通过或不通过。

双学段矩阵通过时，结论最多表述为“固定小学科学与初中数学夹具可通过同一知识、讲解和视觉契约运行”。不得表述为“小学至初中全年级已覆盖”“学段适配已经产生学习效果”或“任意知识均可稳定生成”。
