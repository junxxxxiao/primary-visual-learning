# H5 优先并隔离运行生成视觉代码

首个动态产品验证采用 H5 核心体验和微信入口，因为产品允许模型生成视觉代码，而纯微信小程序的动态代码限制与该能力存在根本冲突。生成代码只能在与主应用权限和儿童数据隔离的视觉沙箱中运行，展示前必须通过安全检查和教学正确性契约；约 45 秒仍未通过时使用渐进图解硬降级。H5 优先是验证选择，不代表最终生产载体已经冻结。

## Consequences

- 微信小程序壳只承担入口、权限和 WebView 边界验证；
- 沙箱不得访问网络、存储、设备权限、主 DOM 或儿童数据；
- 已验证场景可以按知识、契约、代码和测试版本缓存；
- 未经验证的生成场景不得展示给儿童；
- TS-00、TS-04A、TS-04B 和 TS-06 是进入垂直 MVP 开发的前置证据。
