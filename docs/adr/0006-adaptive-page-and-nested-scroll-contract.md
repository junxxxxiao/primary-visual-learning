# 所有交互页面共用自适应页面与分层滚动契约

研究原型、高保真设计和后续进入 `apps/`、`packages/` 的实际产品实现，必须共用同一份响应式滚动契约。页面文档负责整体浏览；灰色讲解画布只在内容超高时成为条件性内部滚动区；小知对话记录在抽屉或平板常驻栏内独立滚动。该决策替代 ADR-0004 的“页面外壳不得整体滚动”规则，并修订 ADR-0003 第 8 条对短屏画布滚动的引用。

这项决策规定可验证的产品行为，不锁定生产框架、CSS 方案或组件库。视觉场景的构图、运动包络和非矩形内部安全区继续由 [ADR-0003](0003-visual-scene-layout-contract.md) 负责，讲解时序继续由 [ADR-0005](0005-lesson-runtime-state-and-timeline-contract.md) 负责。

## Contract

每个交互页面至少声明：

- `viewport_profiles`：真实手机、短可视高度手机、平板和宽屏布局；
- `primary_scroll_owner`：默认必须为页面文档；固定审阅模式使用语义等价的模拟页面视口；
- `conditional_scroll_owner`：内容确实超过可视高度时允许滚动的灰色讲解画布；
- `conversation_scroll_owner`：手机抽屉或平板常驻栏中的对话记录区；
- `overlay_scroll_owner`：Modal、底部抽屉等独占式覆盖层；
- `sticky_regions`：滚动期间保持可见的导航、播放器和当前任务主操作；
- `safe_area_tokens`：底部系统安全区和产品最小安全距离；
- `scroll_restoration`：页面、画布和对话记录的进入、返回、旋转及断点切换恢复策略；
- `review_profiles`：固定审阅画布及真实响应式视口的验收矩阵。

## Invariants

1. 页面文档是手机、平板和宽屏页面的主要纵向滚动容器。内容不足一屏时页面至少铺满动态视口；内容超过一屏时必须自然增加页面高度并可到达全部内容，不得通过固定高度或 `overflow: hidden` 裁切。
2. 灰色讲解画布只在其完整教学内容超过可视高度时成为条件性纵向滚动容器。手势从画布内开始时画布优先滚动；画布到达顶部或底部后，后续同方向滚动必须自然传递给页面。画布不得产生横向滚动，也不得降低 ADR-0003 的完整内容布局范围、运动包络和隐藏裁切检查。
3. 每个页面最多声明一个普通内容内部纵向滚动区。不得让画布内部组件、答案列表和页面同时形成无法识别的嵌套滚动链；Modal、抽屉和明确的平板常驻对话栏除外。
4. 手机小知抽屉属于独占式 Overlay 滚动上下文。抽屉展开时锁定页面和讲解画布；标题、关闭入口和输入操作保持可见，中间对话记录区是唯一纵向滚动容器，且滚动不得穿透至背景。
5. 平板常驻小知对话栏是与页面、画布并列的独立滚动区，不锁定背景；触控、触控板或指针所在区域拥有当前手势。常驻对话栏到达边界时不得串滚页面。平板采用 Overlay 抽屉时遵循第 4 条。
6. 页面切换默认回到新页面顶部；返回上一页面时恢复其页面滚动位置。旋转、断点切换和抽屉开关不得丢失页面、画布、对话记录及讲解现场的合理位置。
7. 导航、播放器、小知挂件和当前任务主操作必须位于共享安全区域。sticky 或 fixed 组件不得遮挡正文、画布最终内容或焦点目标；正文必须预留等高空间和 `scroll-padding`。
8. 所有可视元素必须位于所属区域边界。验证同时比较元素边界框、运动包络以及 `scrollWidth/scrollHeight` 与 `clientWidth/clientHeight`；可观察的隐藏裁切、横向滚动、滚动陷阱、穿透滚动或不可达操作均判定失败。
9. 显式固定手机审阅模式使用 `390 × 844` 模拟页面视口，不依赖外层桌面窗口宽度；它可以用内部容器模拟页面文档滚动，但不得改变 C 端路由、讲解、交互、持久化或能力门禁。
10. 所有 C 端手机页面背景和共享外壳从视口顶部开始，不显示、定义或消费独立顶部安全区空白带。底部 Home Indicator 安全区继续由共享 Token 统一处理。

## Verification seam

原型与实际产品实现应跨越同一个 `validateResponsiveScroll(page, viewport, state)` 验证接缝，至少返回：

```json
{
  "primary_scroll_owner": "document",
  "conditional_scroll_owner": "lesson_canvas",
  "conversation_scroll_owner": "tutor_thread",
  "overlay_open": false,
  "horizontal_overflow": false,
  "unreachable_controls": [],
  "scroll_traps": [],
  "result": "pass"
}
```

验收至少覆盖固定 `390 × 844` 手机画布、真实 `360 × 800`、带浏览器工具栏的 `390 × 740`、基准平板和宽屏，并在页面顶部、中段、底部以及画布顶部、中段、底部验证滚动。还必须检查小知抽屉打开与关闭、平板常驻对话栏、页面返回、旋转或视口变化、焦点移动及减少动态效果状态。

## Consequences

- 页面外壳不再使用固定 `100dvh` 高度配合 `overflow: hidden` 作为常规布局策略；使用 `min-height` 保底并让内容自然扩展；
- 普通页面不建立局部纵向滚动容器；画布、对话记录和独占 Overlay 必须使用共享组件显式声明滚动身份；
- 真实产品中画布确实可滚时，应提供兼容减少动态效果的边缘提示；当前内容未溢出的固定 Demo 不显示无意义提示；
- PR 和技术切片必须报告各视口的页面、画布、对话区和 Overlay 滚动归属及机器可读结果；
- 共享外壳或滚动契约变化必须使相关截图、布局夹具和缓存验收结果失效并重新验证；
- 本 ADR 确认产品级行为和验证接口，不代表生产响应式运行时已经实现。
