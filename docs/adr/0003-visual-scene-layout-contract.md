# 所有视觉场景共用版本化生成与排版契约

固定原型、人工编排动画、模型生成动画和静态降级图解必须共用同一份视觉场景布局契约。契约是场景进入讲解画布前的统一接口：调用方只声明目标视口、画布安全内边界、场景根节点、关键状态和运动包络；契约实现负责响应式构图检查、完整可见性检查、可读性检查、状态采样、失败处置和验证记录。不得在学科、题目或页面分支中另建较弱的局部规则。

这项决策规定可证伪的行为约束，不提前锁定生产框架、渲染库或具体检测实现。TS-04B 负责用确定性正负夹具验证该接口能否可靠阻止不合格场景展示和进入缓存；TS-04C 再验证真实模型产物能否在完整讲解上下文中通过同一接口及独立人工评审。

## Contract

每个视觉场景至少声明：

- `contract_version`：布局契约版本；
- `viewport_profiles`：至少覆盖手机竖屏和平板的独立布局模式，不得把横向构图直接缩小为手机构图；
- `canvas_inner_bounds`：扣除安全留白后的可用画布范围；
- `local_safe_regions`：圆弧、圆角、气泡、瓶体等非矩形容器的内部安全内容区；
- `scene_root`：接受统一布局与绘制隔离的场景根节点；
- `states`：起始、全部关键帧、最终、暂停、恢复、交互后和减少动态效果状态；
- `motion_envelopes`：所有运动主体的完整轨迹包络，而非只声明起点和终点；
- `readability_limits`：对应视口的最小文字、图形辨识和触控尺寸。

最小验证结果采用机器可读结构，并能定位具体违规：

```json
{
  "contract_version": "visual-layout/v1",
  "scene_version": "example-scene/v1",
  "viewport": "phone",
  "state": "keyframe-2",
  "result": "pass",
  "violations": []
}
```

实现可以扩展字段，但不得把控制台警告或人工肉眼判断当作 `pass`。

## Invariants

1. 文字、公式、图片、图形、标注、交互控件、动画主体及其完整运动轨迹必须位于画布安全内边界；不得覆盖标题、字幕、播放器、对话框或页面留白。非矩形容器中的内容还必须位于其 `local_safe_regions`，仅落在容器矩形包围盒内不构成通过。
2. 手机和平板必须分别组织信息层级、运动方向、主体尺寸、画面密度和安全留白；内容放不下时必须重排、缩小主体或压缩间距，不能裁掉教学内容。
3. `overflow: hidden`、`clip` 和遮罩只承担绘制隔离，不构成验收证据。验证必须同时比较可见元素及运动包络的边界框与画布内边界，并比较全部相关容器的 `scrollWidth/scrollHeight` 和 `clientWidth/clientHeight`，发现隐藏裁切即失败。
4. 验证必须覆盖起始、关键过程、最终、暂停、恢复、交互后和减少动态效果状态；内容揭示、子片段切换、交互与视口变化后必须重新验证。
5. 每个视口和状态都必须返回 `pass/fail` 及违规元素、违规类型和边界数据。任一必测状态失败，整个场景即失败。
6. 失败场景不得作为有效场景展示或缓存。系统先尝试重排或重新生成；仍失败时使用同样受契约检查的渐进静态图解硬降级，不展示被裁切的半成品。
7. 缓存身份必须包含布局契约版本、场景版本、视口、知识依据版本、代码哈希和测试版本；契约变化必须使旧缓存失效并重新验证。
8. 按照 ADR-0006，灰色讲解画布仅在完整内容超过可视高度时成为条件性纵向滚动视口；`canvas_inner_bounds` 指完整内容布局范围，而非当前露出的矩形。场景及运动包络必须完整位于该范围内，不得产生横向滚动、隐藏裁切或越过画布进入页面外壳。

## Verification seam

固定原型与未来生成运行时跨越同一个 `validateVisualScene(scene, viewport, state)` 验证接缝，返回结构化结果；生成器、缓存和展示层只消费该结果，不复制判定逻辑。具体 DOM、SVG、Canvas 或其他渲染适配器可以不同，但必须满足同一接口和同一夹具集。

TS-04B 至少使用手机和平板夹具验证：正常场景、元素越界、非矩形容器内部安全区越界、隐藏裁切、仅中间轨迹越界、暂停/恢复后越界、减少动态效果越界、视口切换越界和静态降级越界。候选门槛为已知违规拦截率 `100%`、未通过场景展示或缓存为 `0`。

## Consequences

- 新学科和新题目只提供场景声明，不得降低全局门禁；
- 原型审阅必须同时运行固定 `390 × 844` 手机视口和基准平板视口，并逐状态保留机器可读结果；
- 视觉正确但布局契约失败的场景仍属于不可展示场景；
- 本 ADR 已确认规则与验证接口，尚不证明动态生成、自动重排或生产运行时已实现。
