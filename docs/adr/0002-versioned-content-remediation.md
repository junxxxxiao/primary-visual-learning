# 按内容版本批量修订并使学习结果失效

讲解、视觉场景和迁移任务都必须关联不可变内容版本。关键知识错误由具备授权的人工在内部确认，系统按版本停用内容、定位受影响探索、使原学习结果失效并提供重新验证；不能静默覆盖内容后继续保留旧学习结论，因为原结论建立在已经失去可信基础的讲解和评测上。

## Consequences

- 普通客服不能直接修改学习结果；
- 修订记录包含授权人、时间、原因、严重程度、影响范围和替代版本；
- 安全严重错误可以先熔断，再等待人工确认；
- 家长在查看受影响记录时看到修订提示，必要时主动通知；
- 删除审计只保留修订事实，不保留被删儿童内容。
