# 所有交互页面共用响应式外壳与滚动归属契约

研究原型、高保真设计和后续进入 `apps/`、`packages/` 的实际产品实现，必须共用同一份响应式交互外壳契约。契约负责设备视口、页面区域、滚动归属、安全区、固定操作和共享组件边界；不得把原型中的手机适配规则当作只用于 Demo 的临时样式。

这项决策规定可验证的产品行为，不锁定生产框架、CSS 方案或组件库。视觉场景自身的构图、运动包络和非矩形内部安全区继续由 [ADR-0003](0003-visual-scene-layout-contract.md) 负责。

## Contract

每个交互页面至少声明：

- `viewport_profiles`：真实手机、短可视高度手机、平板及宽屏布局；
- `shell_regions`：导航、标题、内容或讲解画布、播放控制、主操作和辅助交互区域；
- `safe_area_tokens`：底部系统安全区及产品最小安全距离；C 端手机页不得声明独立顶部安全区空白带；
- `scroll_owner`：可视高度不足时唯一允许滚动的区域；
- `fixed_controls`：必须持续可见、可触达的主操作、小知挂件和播放控制；
- `shared_components`：跨学科、预设和页面复用的组件身份；
- `review_profiles`：固定审阅画布及真实响应式视口的验收矩阵。

## Invariants

1. 显式固定手机审阅模式使用 `390 × 844` 画布，其布局不得依赖外层桌面浏览器宽度；无显式审阅参数时必须按真实窗口和动态可视高度响应。审阅模式只能改变验收视口，不得改变 C 端路由语义、讲解或交互状态、持久化、能力门禁及可见产品界面。
2. 常规手机优先在单屏内完整呈现导航、标题、核心内容、播放控制和主操作。可视高度不足时，页面外壳不得整体滚动，只允许已声明的内容区或灰色讲解画布外层滚动视口内部纵向滚动；不得产生横向滚动。讲解画布作为滚动归属时，不降低 ADR-0003 对其完整内容布局范围内场景边界、运动包络和隐藏裁切的检查。
3. 小知挂件、播放控制和当前任务的主操作必须位于各自共享安全区域内，在内容滚动、动态工具栏、方向变化和内容揭示后仍完整可见、可触达且不遮挡教学内容。
4. 讲解或实验页底部的主要继续操作必须在其画布或独立主操作区域内水平居中，不得以外边距、变换或绝对定位越过所属区域边界。
5. 所有可视元素必须位于所属区域边界。验证同时比较元素边界框和 `scrollWidth/scrollHeight` 与 `clientWidth/clientHeight`；可观察的隐藏裁切、被遮挡操作或越界均判定失败，不能用 `overflow: hidden`、`clip` 或遮罩伪装通过。
6. 相同导航、标题状态组、播放器、小知挂件、抽屉和主操作必须使用共享组件。页面级选择器不得复制或部分覆盖定位属性；修改后必须审计全部使用页面。
7. 手机与平板必须分别组织布局。固定审阅模式、真实短屏和宽屏中的任一必测状态失败，页面即不通过验收。
8. 所有 C 端手机页面的背景和共享外壳必须从视口顶部开始，不显示、定义或消费独立的顶部安全区空白带；入口、提问、确认、校准、预测、加载、讲解、迁移、结果和弹层不得建立局部例外。底部 Home Indicator 安全区继续由共享 Token 统一处理。

## Verification seam

原型与实际产品实现应跨越同一个 `validateResponsiveShell(page, viewport, state)` 验证接缝，至少返回页面、视口、状态、滚动归属、固定控件可见性和边界违规。实现可以使用不同 DOM、原生视图或跨端框架适配器，但不得降低同一夹具集和通过标准。

验收至少覆盖：固定 `390 × 844` 手机画布嵌入宽桌面窗口、真实 `360 × 800`、带浏览器工具栏的 `390 × 740` 短屏、基准平板和宽屏；并检查初始、加载、内容揭示、暂停、恢复、滚动、抽屉展开、方向或视口变化及减少动态效果状态。

## Consequences

- 后续生产应用初始化时必须实现该契约，不得从 Demo 复制一组页面级偏移作为响应式方案；
- PR 和技术切片必须报告各视口的页面滚动归属、固定控件边界和机器可读结果；
- 共享外壳或组件契约变化必须使相关截图、布局夹具和缓存验收结果失效并重新验证；
- 实际产品中只有在内容确实需要滚动时，才应提供“下方仍有内容”的可感知提示；具体动效与可访问替代表达留待生产设计决定，当前内容未溢出的固定 Demo 不新增该提示；
- 本 ADR 确认产品级行为和验证接口，不代表生产响应式运行时已经实现。
