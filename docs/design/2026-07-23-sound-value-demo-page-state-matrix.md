# 声音价值 Demo 页面与状态矩阵

> 日期：2026-07-23  
> 状态：高保真制作输入  
> 范围：固定声音主题公开体验 Demo，不是完整产品 Demo  
> 对应规范：[声音高保真价值 Demo 规范](2026-07-22-sound-value-demo-spec.md)  
> 当前实现：[prototype/](../../prototype/)

## 1. 文档目的

本矩阵用于回答三个问题：

1. 声音价值 Demo 需要完成哪些高保真页面；
2. 每个页面必须设计哪些关键状态和分支；
3. 后续把高保真视觉接入现有交互逻辑时，哪些状态必须保持一致。

矩阵采用“页面矩阵 + 状态矩阵 + 分支流程”三层结构。页面不等于单张静态图：播放、暂停、选择、禁用、恢复和降级等会显著改变理解或操作的状态，都属于高保真交付范围。

## 2. 事实源与冲突处理

本矩阵按以下顺序取值：

1. 已确认的[声音高保真价值 Demo 规范](2026-07-22-sound-value-demo-spec.md)及其 2026-07-23 补充；
2. 当前 `prototype/app.js` 中已经实现的公开体验状态逻辑；
3. 较早的[执行 Brief](2026-07-22-sound-value-demo-execution-brief.md)。

已确认的消歧：

- “慢放观察”是核心讲解结束后的实验操作，不是独立追问；
- 唯一关联追问是“如果没有空气呢？”；
- 打断只保存主题、子片段、力度、速度和完成状态，不保存子片段内具体时间；
- 返回琴弦主题时从被打断子片段开头自动重播；
- 核心三段讲解完成即开放迁移，实验与关联追问均为可选项；
- 公开 Demo 不进入完整产品首页、家长端、历史记录或通用失败页。

## 3. 范围

### 3.1 纳入高保真

- 公开入口和固定能力声明；
- 文字、拍照、语音三种提问入口体感；
- 来源对应的问题确认；
- 响度与音调词义校准；
- 预测、准备、问题引入和三段核心讲解；
- 讲解后的琴弦实验、双视图和慢放；
- 手机轻点小知悬浮入口后打开追问抽屉，并在抽屉内完成模拟语音录入；
- 真空关联主题、主题连接语和现场恢复；
- 音叉首次迁移、失败后的木琴迁移；
- 主观反馈、三类结果、问卷已配置和未配置状态；
- 手机竖屏、平板横屏、平板竖屏宽版和减少动态效果。

### 3.2 明确排除

- 完整产品首页、知识星球、历史记录和家长工作台；
- 登录、儿童档案、家长 PIN、长期画像和生产设置；
- 真实相机、麦克风、OCR、ASR、任意问题和动态生成；
- 分数主题、支付、问卷存储和内测群承载；
- 当前原型中仅供研究直达的 `home`、`askPhoto`、`askVoice`、`failure` 等旧画板。

## 4. 完整体验流程

```text
S01 公开入口
  → S02 发起问题（文字 / 拍照 / 语音）
  → S03 问题确认（来源对应旁白）
  → S04 词义校准（先响度、后音调）
  → S05 预测
  → S06 讲解准备
  → S07 问题引入
  → S08 核心讲解（三段自动连播）
      ├─ 可选：S10 小知追问 → S11 真空主题 → 连接语 → 回到 S08 原子片段开头
      └─ 讲解完成：S09 动手实验，或直接进入迁移
  → S12 音叉迁移
      ├─ 结论与原因均通过 → S14 主观反馈
      └─ 任一维度未通过 → S13 木琴迁移 → S14 主观反馈
  → S15 结果
      ├─ 问卷已配置 → 打开外部问卷
      ├─ 问卷未配置 → 本地提示
      └─ 重新体验 → S01
```

## 5. 页面矩阵

| 编号 | 页面 / 设计面 | 核心目的 | 必须出现的内容 | 主要操作与去向 | 高保真重点 |
| --- | --- | --- | --- | --- | --- |
| S01 | 公开入口 | 说明 Demo 价值和能力边界 | 约 4 分钟、固定主题、不识别任意问题、不调用权限、不登录、不保存儿童个人信息 | 开始体验 → S02 | 第一屏建立可信度；视觉直接表达琴弦、音叉和振动观察，不像完整产品首页 |
| S02 | 发起问题 | 在同一个输入框中呈现文字、语音和拍照三种入口 | 默认填入固定问题的真实文字输入框；用户可用键盘编辑；输入框内语音与拍照图标及发送按钮、不会请求权限或上传的说明 | 修改文字或选择输入图标；发送问题 → S03；返回 → S01 | 保留高保真单 composer；默认值锁定为 Demo 问题，但输入控件本身可真实打字 |
| S03 | 问题确认 | 只确认用户准备提交的问题 | “你想问的问题是”、固定问题、来源匹配的简短语音旁白、修改问题与确认按钮 | 修改问题 → S02；确认 → S04 | 保持单一确认焦点；不恢复来源卡、学习目标或公平比较说明 |
| S04 | 词义校准 | 先分清响度和音调，不泄露答案 | 与 S05 共用的三阶段侧边导航、响度定义与示例、音调定义与示例 | 先播放响度，再解锁音调；两组完成 → S05 | 浅色侧边导航；第三阶段固定命名为“问题讲解” |
| S05 | 预测 | 记录孩子原始判断 | 黄金问题、公平条件、会更高/基本不变/不确定 | 选择后去验证 → S06；返回 → S04 | 不能提前通过颜色或文案暗示正确答案；未选时主按钮禁用 |
| S06 | 讲解准备 | 用一次约 3.2 秒短等待建立即将观察的对象 | 琴弦准备图、固定说明、一次性进度、返回 S01 的按钮 | 自动完成 → S07；返回 → 弹出确认后回 S01 | 不设计研究失败入口；画面不可遮挡文案；等待结束自动前进 |
| S07 | 问题引入 | 作为问题讲解的第一个子片段建立公平比较 | 与 S08 一致的讲解框架、黄金问题、固定条件、三段导航、连续对话；不显示开始或重听按钮 | 自动播放 → S08；追问 → S10；返回 → 弹出确认后回 S01 | 保留高保真连续讲解骨架，不再加入独立中心 CTA 或重听控件 |
| S08 | 核心讲解 | 连续完成公平比较、现象观察、原理命名与结论 | 三个子片段分别使用公平条件、双弦振幅对比、概念因果归纳三套动画；播放器、三段导航、连续对话、语音输入图标、返回图标 | 自动连播；暂停/续播/拖动/上下段；麦克风在当前画布内展开录音；返回 → 弹出确认后回 S01；完成后播放过渡旁白再进入 S09 | 字幕默认关闭并按当前音频逐句同步；图解节点按旁白语义时间点揭示，因果箭头先于对应结论完成；动画结束后冻结最终帧，过渡旁白结束才跳转；播放按钮与进度条同一行 |
| S09 | 动手实验 | 亲手验证拨弦幅度与观察结果 | 一根静止的琴弦、无振动的记录图、四项指标均为等待态；有效拨动后才更新；无效操作达到触发条件后才显示保底按钮 | 拨动琴弦；迁移 → S12；追问 → S10；返回 → 弹出确认后回 S01 | 与 S08 共用顶部与对话结构；保留“琴弦振动”并新增独立“实验”Tab，实验状态下高亮“实验”；无默认力度、振动或指标结论 |
| S10 | 小知追问状态 | 在不改变当前画布的前提下完成延伸追问 | 不是独立页面；保留触发时的讲解或实验画布与 URL，在当前对话区展开录音卡；手机使用底部抽屉并提供右上角关闭；包含取消叉和直接提交对勾 | 手机轻点小知只打开抽屉、长按才录音；文字发送提交输入框当前内容；叉号取消并恢复抽屉默认态；对勾提交当前转写 → S11 | 运行时不路由到固定 S10 页面；录音卡吸附在输入框上方且输入框始终可见；抽屉使用黑色半透明背景蒙层覆盖原画布且不重排画布 |
| S11 | 真空关联主题 | 在同一对话中解释振动与声音传播的区别 | 三段分别使用问题拆分、空气接力、真空阻断三套动画；空气接力在平板使用横向因果链，在手机重排为琴弦 → 空气接力 → 耳朵的纵向信息流并合理占满画布；完整继承并持续保存已提交的问题与回答；手机沿用 S07–S10 同一抽屉、右上角关闭与背景蒙层；此时三枚主题 Tab 全部可见 | 进入时抽屉保持收起并自动播放讲解；点击小知才打开；点击已解锁的琴弦振动 / 实验 / 真空中的声音切换；最终动画冻结，连接语结束后回到被打断主题；返回 → 弹出确认后回 S01 | Tab 按阶段解锁：核心讲解阶段仅琴弦振动，讲解完成后出现实验，提交延伸问题后才出现真空中的声音；手机和平板均不得出现主体挤在局部或大面积无意义空白 |
| S12 | 音叉迁移 | 在新对象上分别验证结论和原因 | 同一个音叉、轻敲/重敲、音调判断、原因判断；默认均未选择 | 两项选完提交；全对 → S14；任一错误 → S13；返回 → 弹出确认后回 S01 | 提交前不揭示正确答案；两个维度独立记录；不能在原题反复选到正确 |
| S13 | 木琴迁移 | 用提示后的新情境再次验证 | 针对性提示、同一音条、响度/音调/原因三项判断；默认均未选择 | 三项选完提交 → S14；返回 → 直接回 S01 | 明确“提示后换一个新情境”；不是音叉题换皮；同时验证响度、音调和原因；不显示返回确认 |
| S14 | 主观反馈 | 收集是否讲清楚，不替代客观迁移结果 | 讲明白/还有一点不懂/没讲明白；补充原因可多选并保存 | 选择后完成 → S15；可跳过 → S15；返回 → 直接回 S01 | 主观反馈与学习结果视觉上分离；补充原因作为结构化反馈保存 |
| S15 | 结果与招募 | 总结过程证据并承接问卷 | 返回按钮、居中结果标题、合并在同一模块中的完成摘要、实验/追问/迁移证据、家庭协助未确认、核心发现与固定 Demo 声明 | 返回 → 直接回 S01；打开问卷；重新体验 → S01 | 三类结果不可只靠颜色区分；未确认/未通过使用红色系状态，同时保持文字标签；S15 不弹返回确认 |

## 6. 状态矩阵

### 6.1 入口、提问、确认与校准

| 页面 | 状态 | 触发 | 视觉与行为要求 |
| --- | --- | --- | --- |
| S01 | 默认 | 首次打开或重新体验 | 开始按钮可用；无登录、权限或产品导航 |
| S02 | 默认输入 | 进入页面 | 一个输入框默认填入固定问题；文字、语音与拍照入口都位于输入框内 |
| S02 | 拍照入口 | 选择拍照图标 | 后续实现使用固定琴弦图片；不打开相机、不请求权限 |
| S02 | 语音入口 | 选择语音图标 | 后续实现使用固定转写；不打开麦克风、不请求权限 |
| S03 | 问题确认 | 来自任一输入入口 | 只显示待确认问题；不显示来源标签或对应旁白 |
| S04–S05 | 阶段导航 | 进入校准或预测 | 两页使用同一浅色三阶段导航，第三项为“问题讲解” |
| S04 | 初始 | 尚未播放 | 响度可播放；音调锁定；继续按钮禁用 |
| S04 | 响度已听 | 完成第一组 | 显示响度观察结论；音调解锁；继续仍禁用 |
| S04 | 两组已听 | 完成第二组 | 两张卡均标为已听；继续按钮可用；均支持再听 |
| S05 | 未选择 | 首次进入 | 三个选项中性呈现；去验证禁用 |
| S05 | 已选择 | 选择任一答案 | 仅显示“已选”，不显示正误；去验证可用 |

### 6.2 准备与核心讲解

| 页面 | 状态 | 触发 | 视觉与行为要求 |
| --- | --- | --- | --- |
| S06 | 准备中 | 从预测进入 | 一次性进度和独立校准动效；结束自动进入 S07 |
| S07 | 第 1 子片段 | 进入问题讲解 | 与 S08 共用顶部、画布、三段导航和连续对话；自动开始第一段 |
| S08 | 子片段预览 1 秒 | 进入任一新片段 | 新画面先稳定出现，再自动播放旁白 |
| S08 | 自动播放 | 预览结束 | 文案、标注、图解与旁白按统一时间轴渐进出现 |
| S08 | 暂停 | 点击暂停 | 已显示内容保留，不回退、不隐藏 |
| S08 | 拖动进度 | 拖动当前片段 | 画面随时间轴同步更新；松开后从新位置自动播放 |
| S07–S11 | 统一播放器 | 进入任一有讲解进度的页面 | 左侧播放 / 暂停按钮、三段可点击进度轨道和当前段落标签使用同一组件；进度跟随真实音频时间更新，点击任意段后切换并自动播放 |
| S07–S11 | 字幕开关 | 点击底部统一播放器中的字幕控制 | 在演示画布下方居中显示当前正在播放的逐句旁白；字幕随音频时间切换，使用半透明深色背景；再次点击关闭；顶部导航不得出现字幕入口 |
| S08 | 手动切段 | 点子片段或上下段 | 从目标片段开头经历同样的 1 秒预览并自动播放 |
| S08 | 第 1 段 | 公平比较 | 同一根弦；长度、松紧、粗细不变；只改变力度 |
| S08 | 第 2 段 | 现象观察 | 轻拨/用力拨的摆动范围对比；往返次数相近 |
| S08 | 第 3 段 | 原理与结论 | 振幅—响度、频率—音调两条因果链；使用“基本不变” |
| S08 | 核心讲解完成 | 第 3 段结束 | 单独播放“现在你可以动手来试试”；显示 S09；迁移入口同时开放 |
| S08 | 返回确认 | 点击顶部返回图标 | 弹窗说明学习进度和已完成记录会保存；提供“继续学习”和“保存并返回”；确认后回 S01，不进入旧儿童首页 |

### 6.3 琴弦实验

| 页面 | 状态 | 触发 | 视觉与行为要求 |
| --- | --- | --- | --- |
| S09 | 初始 | 讲解结束 | 引导先轻拨；用力拨保底操作不可先执行 |
| S09 | 拖动中 | 拖动琴弦 | 琴弦跟随指针；拖动距离表达力度；实时波形与四项文字反馈同步更新 |
| S09 | 轻拨完成 | 有效轻拨 | 琴弦与实时波形显示较小振幅；提示下一步用力拨 |
| S09 | 用力拨完成 | 轻拨后有效重拨 | 显示更大振幅和更响声音；频率/音调保持基本不变 |
| S09 | 无效操作一次 | 拖动不足 | 只给轻量提示，不立即出现保底按钮 |
| S09 | 保底按钮出现 | 连续两次无效操作 | 显示“轻拨一次/用力拨一次”；仍保持先轻后重顺序 |
| S09 | 减少动态效果 | 系统或设置开启 | 使用等价关键状态图表达振幅差和频率相近，不依赖位移动画 |

### 6.4 追问、真空主题与恢复

| 页面 | 状态 | 触发 | 视觉与行为要求 |
| --- | --- | --- | --- |
| S10 | 小知默认 | S08/S09 | 手机只显示小知悬浮图标与“按住问老师”提示气泡，不显示语音或发送图标；平板保留轻量对话区 |
| S07–S11 | 小知挂件与抽屉 | 手机轻点小知悬浮图标 | 收起挂件的头像、提示文案、气泡和点击区域完全一致；抽屉左右贴边；消息气泡、间距、字号、对齐和底部输入组件保持一致，仅内容可变；右上角可关闭；背景显示黑色半透明蒙层；原讲解或实验画布保持原尺寸与位置。进入新主题不会自动展开抽屉 |
| S10 | 模拟录入 | 手机长按小知或点击抽屉内麦克风 | 在抽屉内显示录音波形、固定转写、取消叉与完成对勾；底部输入框保持可见 |
| S10 | 录入完成 | 儿童点击对勾 | 结束录入状态并直接提交唯一固定问题；完整消息记录继续保留；进入 S11 |
| S10 | 取消录入 | 儿童点击叉叉 | 清理本次语音转写，回到抽屉默认态；不提交、不进入 S11 |
| S10 | 取消录入 | 返回或离开录入状态 | 清理模拟录入；若进入前正在播放，则从原进度续播 |
| S11 | 真空 1/3–3/3 | 提交追问 | 使用与 S08 相同的讲解框架；在同一个对话区追加儿童追问与小知回答 |
| S11 | 连接语 | 真空第 3 段结束 | 保持最终画面；播放器与切段按钮禁用；自然连接两个主题 |
| S11→S08 | 自动恢复 | 连接语结束 | 恢复力度、慢放和完成状态；从被打断子片段开头自动播放 |

### 6.5 迁移、反馈与结果

| 页面 | 状态 | 触发 | 视觉与行为要求 |
| --- | --- | --- | --- |
| S12 | 初始 | 进入音叉迁移 | 音调和原因均未选；提交禁用 |
| S12 | 部分选择 | 只完成一项 | 已选项清晰；提交仍禁用；不显示正误 |
| S12 | 首次通过 | 音调基本不变 + 振幅原因 | 记录 `first-pass`；进入 S14 |
| S12 | 首次未通过 | 任一维度错误 | 不在原题纠错；给针对性提示并切换 S13 |
| S13 | 提示后初始 | 音叉未通过 | 显示提示和新对象；三项均未选；提交禁用 |
| S13 | 提示后通过 | 三项全对 | 记录 `prompted-pass`；进入 S14 |
| S13 | 提示后仍未通过 | 任一维度错误 | 记录未完整通过；进入 S14，不继续增加题目 |
| S14 | 未选择 | 首次进入 | 完成禁用；跳过可用 |
| S14 | 已选择“讲明白” | 主观选择 | 不显示追加原因；完成可用 |
| S14 | 已选择未讲清 | 选择其他两项 | 显示讲太快/动画没看懂/想换讲法等补充项；补充原因可多选并随主观反馈保存；完成可用 |
| S15 | 自己弄懂了 | 结论和因果均通过 | 显示两项通过及首次/提示后完成方式 |
| S15 | 部分理解 | 只通过一个维度 | 明确哪一项通过、哪一项未通过，不只显示总标签 |
| S15 | 建议陪一陪 | 两个维度均未通过 | 使用支持性文案，不惩罚、不展示分数或排名 |
| S15 | 可选体验未完成 | 未做实验或真空追问 | 如实显示“未完成”，但不改变迁移得出的结果分类 |
| S15 | 问卷已配置 | `SURVEY_URL` 有效 | 当前浏览器打开外部问卷 |
| S15 | 问卷未配置 | `SURVEY_URL` 为空 | 留在结果页并提示“问卷链接尚未开放” |

## 8. 响应式矩阵

| 场景 | 手机竖屏 | 平板横屏 | 平板竖屏宽版 |
| --- | --- | --- | --- |
| 入口与提问 | 单列，主操作靠近拇指区 | 文案与视觉双区 | 单列加宽，不压缩成窄列 |
| 核心讲解 | 顶部状态、渐进文字、实验区、底部播放器同屏；不横向分栏 | 渐进文字、主实验、轻量对话三栏；实验最大 | 采用手机式纵向结构的宽版 |
| 琴弦实验 | 可拨琴弦、实时波形与四项文字反馈纵向组合 | 琴弦为主画面，实时波形与文字反馈同屏 | 根据可用宽度切换，不丢当前拨弦幅度 |
| 小知 | 右下小知悬浮图标；点击后打开底部抽屉，原画布不重排 | 常驻轻量对话区，录入状态在区内切换 | 使用手机悬浮入口或窄对话区，不能改变实验画布布局 |
| 迁移与结果 | 对象在上、答案在下，允许页面滚动 | 对象与答案并排 | 单列宽版 |

基准验收视口：`360×800`、`390×844`、`1180×820`、`1366×768`。旋转或布局切换不得丢失播放进度、当前主题、子片段、实验力度、慢放状态或迁移答案。

## 9. 高保真制作批次

### A. 主体验骨架

S01–S08：入口、三种提问入口、确认、校准、预测、准备、问题引入和三段核心讲解。先验证价值叙事、信息层级和四分钟体验节奏。

### B. 核心互动与追问

S09–S11：琴弦实验、双视图、小知覆盖层、两条追问路径、真空主题和恢复。重点验证触摸目标、遮挡、音画同步和现场连续性。

### C. 迁移与收口

S12–S15：音叉、木琴、主观反馈、三类结果与问卷两态。重点验证结果判定与体验招募之间的可信衔接。

每个批次均先完成手机竖屏和 `1180×820` 平板横屏，再补齐另外两个验收视口；不等全部静态页面完成后才接入交互。

## 10. 高保真完成定义

- [ ] S01–S15 均有默认高保真设计面；
- [ ] 本矩阵列出的关键状态有可审阅的独立入口或稳定复现方式；
- [ ] 三种输入来源、两条追问路径、两次迁移和三类结果均可完整走通；
- [ ] 页面共用同一套本地 Token 和组件规则；
- [ ] 手机核心讲解和实验单屏无滚动、无覆盖、无裁切；
- [ ] 儿童主要点击目标不小于 48px，键盘焦点可见；
- [ ] 减少动态效果下仍能理解振幅差、频率相近和真空传播结论；
- [ ] 不请求相机、麦克风或登录，不保存儿童个人信息；
- [ ] 不把固定 Demo 表述为真实识别、任意问答或动态生成；
- [ ] 在四个基准视口完成截图、交互和控制台检查；
- [ ] 已验证和未验证范围记录在交付说明中。
