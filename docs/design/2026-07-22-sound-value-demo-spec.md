## 1. 目标与边界

本 Demo 用于从社交媒体向目标家长展示接近真实产品的固定声音学习体验，并把有兴趣的家庭引导到外部问卷和内测群。

它验证价值表达、交互理解和家长报告的儿童体验，不证明真实输入、动态知识、生成视觉、学习效果、生产稳定性或付费意愿。

Demo 不登录、不请求相机或麦克风、不保存儿童个人信息，不提供任意问题输入。

## 2. 体验路径

1. Demo 说明、固定问题的文字/拍照/语音入口体感；
2. 由旁白确认问题，再区分音调和响度；
3. 旁白引导预测“更用力拨同一根弦，音调会更高吗？”；
4. 居中引入问题，按“公平比较—真实现象—原理命名—结论”连续讲解；
5. 讲解结束后单独提示“现在你可以动手来试试”；
6. 讲解中可随时用固定文字或模拟语音入口追问“如果没有空气呢？”；
7. 播放“真空中的声音”关联主题；
8. 关联主题结束后先播放连接两个主题的过渡语，再自动返回并从被打断子片段的开头继续；
9. 核心讲解结束后可选轻拨、用力拨和慢放，也可直接进入迁移；
10. 音叉迁移；
11. 首次失败时使用木琴音条新迁移；
12. 结果、完成方式和问卷入口。

目标时长约四分钟，操作、暂停和回听可以自然延长。

## 3. 视觉系统

方向为“儿童科学实验室 + 清晰讲义”。

- 背景：白色和浅中性灰；
- 正文：石墨黑；
- 主要操作、频率和音调：蓝色；
- 振幅、响度和正向证据：绿色；
- 观察提示：黄色；
- 错误：红色；
- 卡片只用于重复选项和结果证据，核心讲解使用开放画布；
- 圆角不超过 8px，儿童主要点击目标不小于 48px；
- 不使用大面积渐变、装饰光斑、卡片嵌套或幼儿化绘本构图。

琴弦、音叉、木琴和真空场景必须呈现真实对象结构和可观察变量。视觉资产原创，不复用教材扫描图或插画。

## 4. 小知

“小知”是轻量讲解者和追问入口：

- 手机显示在实验区右下、播放控制上方；
- 手机挂件常驻“按住问老师”气泡；轻点打开追问浮层，按住进入模拟语音状态，松开即提交固定问题；
- 平板作为对话区头像；
- 只提供等待、讲解、收到追问和完成等少量状态；
- 不遮挡实验，不承担复杂角色表演；
- 语气温和、好奇、清楚，不卖萌或幼儿化。

## 6. 教学编排

### 6.1 词义校准

先播放同音调、不同响度的声音，再播放响度接近、不同音调的声音。第一组的一轻一响应有明显响度差异，避免儿童需要反复辨认。只建立：

- 响度：听起来有多响；
- 音调：听起来有多高。

预测前不得揭示振幅和频率关系。

### 6.2 控制条件与琴弦操作

明确同一根弦的长度、松紧和粗细不变，只改变拨弦力度。

核心讲解先用不可操作的文字和图解完成问题引入、公平比较、现象观察、生活例子、原理命名和结论。讲解期间不显示可拖动琴弦或实验按钮；最后一段旁白结束后，单独播放“现在你可以动手来试试”的操作邀请，再出现互动实验区。

孩子直接拖动琴弦并松开：先轻拨，再用力拨。拖动距离代表力度。若直接操作连续失败，显示“轻拨一次”和“用力拨一次”保底按钮。

音频必须保持音调基本相同，响度随力度改变。

### 6.3 双视图

左侧或上方显示琴弦慢放，中点有跟踪点和振幅双箭头；右侧或下方同步显示“振动记录图”，记录固定位置随时间上下移动的轨迹。

- 波峰高度对应振幅；
- 固定时间内的往返次数对应频率；
- 轻拨和用力拨的波峰高度不同，波峰数量和间距基本相同；
- 先观察真实琴弦，再解释记录方式，最后命名振幅和频率；
- 不把记录图称为未解释的“波形”。

### 6.4 结论

在限定条件下：

- 更用力主要增大振幅，使声音更响；
- 振动频率和音调基本不变；
- 不使用绝对化的“完全不变”。

## 7. 播放与进度

- 温和、自然的年轻成人普通话预生成合成声；
- 语速约正常成人讲解的 0.9 倍；
- 从问题确认和“猜一猜”开始提供旁白；文案使用短句、设问、回应和自然转折，避免定义堆叠；
- 同一主题的三个讲解子片段在前一段结束后自动进入下一段，无需儿童逐段点击；
- 每个子片段开头先展示新画面 1 秒再播放旁白；自动连播、手动点选及上一段/下一段都使用同样节奏并自动播放；
- 音频、文字、图片、标注和场景使用统一时间轴；
- 支持播放、暂停、当前时间、可拖动进度、上一步和下一步；
- 儿童松开进度条后，从新位置自动恢复播放，不停在暂停态等待再次点击；
- 不提供独立“回退 10 秒”按钮；
- 拖动只作用于当前子片段，并同步恢复整个讲解现场；
- 拖回儿童操作发生前时，不自动重演旧操作；
- 暂停后保留已显示信息；
- 减少动态效果时使用等价关键状态图。

## 8. 追问与现场恢复

Demo 只支持一个固定关联追问，不模拟真实 ASR 或任意回答。

### 8.1 讲解中打断

“琴弦振动”主题从第一段开始即可追问。输入框默认放入“如果没有空气呢？”，儿童可修改文字后直接发送；点击麦克风是独立的模拟语音转写路径，会暂停讲解并只显示不调用设备权限的录音动画，叉号取消本次转写，对勾直接提交当前转写。提交时内部只保存主题、子片段、力度、速度和完成状态，不记录子片段内的具体时间，也不向儿童展示这些内部状态。Demo 不再把“可以慢一点看吗？”作为独立追问选项；慢放保留为讲解后的实验操作。

### 8.2 关联追问

“如果没有空气呢？”是琴弦主题唯一预置追问。直接发送预置文字，或完成模拟语音转写后再发送，都会直接创建“真空中的声音”主题，不再显示二次确认弹窗；该主题展示琴弦仍振动，但没有空气时声音无法通过空气传到耳朵。

真空主题三段播放完成后保持当前画面，先用一句语音连接“琴弦怎样振动”与“声音怎样传播”，再自动恢复原主题、子片段、力度和慢放状态，并从被打断子片段的开头重新播放。恢复位置、锚点、内部保存或返回状态不在儿童端展示；界面只保留自然的主题过渡语。

### 8.3 手机浮层

“小知”从核心讲解开始始终显示在实验区右下、播放控制上方，并显示“按住问老师”气泡。轻点后打开底部对话浮层；按住进入不调用设备权限的模拟语音输入状态，气泡提示“松开就发送”，松开后自动提交固定问题并进入关联主题。按住期间不得触发系统长按菜单；确认固定追问后浮层自动收起，进入关联主题时保持收起，不随页面切换自动展开。已提交的问题和小知回答作为当前体验的连续消息记录，在 S07–S11、实验 Tab、主题切换及返回原子片段后始终保留。

追问区显示可编辑文本框、麦克风图标和发送按钮。琴弦主题输入框预置“如果没有空气呢？”，发送按钮提交输入框当前内容并在同一对话中进入第二个延伸主题；点击麦克风图标展示模拟录入动画，叉号取消，对勾提交当前转写。按钮不会请求麦克风权限，所有回答仍是与固定声音主题匹配的演示内容，不代表任意问题能力。

## 9. 迁移验证

首次迁移：同一音叉被更用力敲击时，把“音调怎样变化”和“为什么”拆成两个独立单选问题。两题都作答后才启用提交，提交前不显示正误。

“琴弦振动”三段核心讲解播放完成后即显示迁移入口，不以轻拨、用力拨、慢放或关联追问是否完成作为门禁。

如果结论或因果验证未通过，给出提示：分别观察振动幅度和相同时间内的振动次数。然后使用同一木琴音条更用力敲击的新情境，分别判断响度、音调和原因。

不得在原题上反复选择至正确。

## 12. 响应式

### 讲解画布硬边界

本 Demo 不定义局部例外，完整遵循系统级[视觉场景布局契约](../adr/0003-visual-scene-layout-contract.md)。所有主题、设备和子片段中的文字、公式、图形、标注、动画主体及其完整运动轨迹必须位于灰色讲解画布安全内边界；手机和平板分别构图。自动验收必须覆盖起始、关键过程、最终、暂停、恢复、交互后与减少动态效果状态，同时检查元素/运动包络边界和 scroll/client 隐藏裁切，并输出机器可读 `pass/fail`。`overflow: hidden`、`clip` 或遮罩只用于绘制隔离，不能裁掉教学内容或使失败状态通过。

### 手机竖屏

固定顶部状态、渐进文字、主视觉实验区和底部播放控制。“小知”从讲解开始始终位于实验区右下；S07–S11 使用同一收起挂件与抽屉组件，头像、提示文案、气泡和点击区域不得出现页面级变体。抽屉左右贴边、右上角提供关闭按钮，展开时使用黑色半透明蒙层覆盖背景且不重排画布；录音卡下方始终保留可编辑输入框。核心讲解、互动实验、三段导航和播放控制必须在单屏内完整呈现，不要求儿童上下滚动；文字区与图解/动画区必须保持明确间距，不得覆盖。页面不使用横向主分栏。

所有 C 端手机页面的背景和共享外壳从画布顶部开始，不显示、定义或消费独立的顶部安全区空白带；入口、提问、确认、校准、预测、加载、讲解、迁移、结果、题图弹层和固定手机审阅画布均不得例外。页面外层只保留各自统一的视觉边距，声音与数学预设不得增加局部覆盖；底部 Home Indicator 安全区继续统一处理。

讲解动画不能直接压缩平板横向构图。手机竖屏应按语义顺序改为纵向信息流，调整运动方向、主体比例和留白；主体不能只集中在画布顶部，也不能以放大元素填满画布造成拥挤。每个子片段需在手机与平板分别检查画面密度、可读性、遮挡、裁切和旁白同步。

### 平板横屏

渐进文字、主实验画面和轻量对话区三栏布局，实验画面占最大面积。

### 平板竖屏与旋转

使用手机式纵向布局的宽屏版本。布局切换不得丢失时间、操作或主题状态。

## 15. 数学真题预设扩展（2026-07-27）

提问页在同一高保真 composer 中提供“声音知识演示”和“数学真题演示”两个固定预设。数学预设的题图缩略图位于输入框内部左侧，固定输入文案为“帮我讲解下这道数学题”，且不可编辑，避免输入与后续固定讲解不一致。图片来自仓库内固定演示资产，不调用真实图片选择、上传或 OCR。

数学路径为：`题图输入 -> 问题确认 -> 讲解准备 -> 四段自动连播讲解 -> 迁移验证 -> 结果`。它跳过声音概念校准、讲解前预测、实验和追问。四段讲解依次覆盖完全平方求极值规律、第（1）题、第（2）题和靠墙围花圃的第（3）题；播放器继续支持播放/暂停、四段切换、拖动定位和逐句字幕。手机将公式与几何关系重组为纵向信息流，平板使用横向对照，不得直接缩放同一构图。

数学讲解页不得另建或删减页面框架。顶部返回与品牌导航、主题标签、统一播放器及其字幕开关、小知挂件、对话面板及手机抽屉全部复用声音 Demo 的共享组件和交互外壳；字幕开关固定属于底部统一播放器，顶部导航只显示返回、品牌、主题和播放状态，不得通过页面选择器或运行时脚本在顶部新增字幕入口。数学预设只替换题目、讲解画面、字幕、当前步骤的对话文案和迁移内容。对话面板展示当前数学步骤的讲解消息，并在 C 端保留追问输入、语音和发送入口的完整外观；这些入口当前不可操作，点击不产生反馈或跳转，也不进入声音关联主题。长按小知挂件仍可打开模拟语音录入外观，但确认后保持当前页面和录音状态，不提交、不提示、不进入声音或真空主题。

数学与声音预设必须共用同一讲解播放契约：每个子片段在自动连播、手动点选、主题切换和返回原主题后，先完整展示起始画面并静置 1 秒，再同步启动旁白、进度和动画。暂停时冻结旁白、进度、动画位置及已经出现的内容；恢复时从同一位置继续，不清空、不重播。真实音频不可用时的视觉降级时间轴也必须保存暂停位置并遵循相同时序。

固定结论为：第（1）题最小值 `-3`；第（2）题最大值 `3`；第（3）题在短边 `25` 米、长边 `50` 米时取得最大面积 `1250` 平方米。迁移题改用 `120` 米木栅栏，首次独立通过需同时选择短边 `30` 米、长边 `60` 米、最大面积 `1800` 平方米，以及 `S = -2(x - 30)^2 + 1800` 的原因。

首次迁移未通过时可以展示配方提示并在同题重答一次。提示已经包含关键变形，因此提示后答对只记为“提示后完成本题，仍需换题验证”，不得记为“提示后弄懂”或稳定迁移通过。结果页分别呈现结论与原因状态，并明确固定题图、固定讲解不代表真实 OCR、任意数学题讲解、知识正确率或学习效果。

加载页不复述问题、不展示输入题图，也不使用主题专属装置；声音与数学预设统一显示“正在生成动画讲解”。提问页中的数学题缩略图支持点击放大查看，关闭后返回原输入状态。
