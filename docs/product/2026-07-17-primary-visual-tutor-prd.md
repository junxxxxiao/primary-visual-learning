## 1. 产品概述

### 1.1 产品定位

面向小学 3–4 年级数学与科学的可打断互动视觉家教。

产品解决的不是“把知识做成动画”，而是：孩子遇到一个具体问题时，可以随时追问、改变条件和换例子；系统保留当前讲解上下文和视觉现场，调整解释，直到孩子能在新情境中独立应用。

儿童主张：

> 你问为什么，AI 现场演给你看。

家长主张：

> 孩子自己把问题弄明白，少陪讲、少冲突，还能看到是否真的学会。

### 1.2 竞争差异

竞品已普遍覆盖预制视频、固定互动、迁移题、错题分析、学习记录和课程推荐。MVP 不以这些能力本身作为差异。

核心差异是“场景内 AI”：系统理解当前问题、正在讲解的主题、当前子片段、视觉参数、孩子刚才的操作和临时追问，并优先修改当前视觉现场，而不是跳到与课程隔离的通用聊天。

一句话对比：

- 步步高：播放教材内容；
- 学而思：按老师预设路径互动；
- 本产品：孩子的问题和操作决定下一步讲什么、怎么演。

## 2. 目标、非目标与成功定义

### 2.1 MVP 目标

1. 让孩子通过拍照、语音或文字提出一个具体数学或科学问题；
2. 用诊断预测和可操作视觉讲解暴露、验证并纠正具体误解；
3. 允许孩子在讲解中通过语音或文字追问；
4. 追问后能够修改当前场景或创建关联讲解主题，并可恢复原现场；
5. 使用迁移题区分“看懂了”和“真正会用了”；
6. 自动形成可回看、可恢复、可从节点继续的探索记录；
7. 让家长看懂孩子原来的想法、系统采取的干预、是否独立完成及是否需要陪伴。

### 2.2 当前非目标

- 完整教材目录和传统课程货架；
- 任意问题均生成高质量动画；
- 全学科、全年级覆盖；
- 开放式儿童聊天机器人；
- 支付、课程商城、多孩子管理、老师协同、远程任务和消息推送；
- 用固定夹具证明真实识别准确率、模型能力或端到端延迟；
- 在 MVP 中承诺生产级长期认知地图；
- 以直接给作业答案作为核心能力。

### 2.3 当前阶段成功定义

当前阶段首先验证交互闭环和技术可行性，不直接声称学习效果成立。

中保真体验通过标准：

- 5 名观察儿童中至少 4 名无需家长解释即可完成主流程；
- 至少 4 名儿童能使用一次互动控制；
- 至少 3 名儿童能独立发起或完成一次追问；
- 至少 4 名儿童能进入关联主题并返回原主题；
- 所有家长均能从“今日”指标定位到对应探索记录；
- 至少 4 名家长能复述孩子原来的想法、关键干预和迁移结果；
- 原始照片和原始语音不进入持久化记录；
- 严重知识错误为 0。

技术指标仅作为后续候选门槛，必须经技术切片重新测量，详见技术验证文档。

## 3. 用户与核心场景

### 3.1 儿童用户

- 小学 3–4 年级；
- 对抽象概念需要可视化、可操作的解释；
- 能提出“为什么”，但未必能准确描述卡点；
- 需要慢放、改变条件、换例子或反事实观察；
- 既有课内求助，也有由课本自然延伸的相关好奇心。

### 3.2 家长用户

- 知道答案但不擅长解释；
- 希望减少陪讲时间和辅导冲突；
- 关心孩子是否真正理解，而不只是时长和正确率；
- 关注内容可信、儿童隐私、开放范围和数据删除。

### 3.3 关键场景

1. 孩子拍下课本或题目中的不懂之处，并补充一句问题；
2. 孩子直接语音或文字问一个“为什么”；
3. 孩子从“知识星球”进入经过审核的预设知识解答；
4. 孩子在讲解中要求慢放、改变条件或提出关联问题；
5. 孩子回看历史，并从某个可恢复节点继续探索；
6. 家长查看今日结果，定位到具体记录并判断是否需要介入；
7. 家长管理保存期限、探索范围和删除操作。

## 4. 产品原则

1. **场景主导**：视觉场景和讲解幻灯片是主体，对话用于解释和控制场景；
2. **追问优先**：孩子可在任何讲解子片段中暂停并追问；
3. **原场景优先**：可以通过参数、速度、标注或对比回答时，不创建新主题；
4. **一次一个重点**：每个子片段只承担一个主要教学结论；
5. **先快后强**：先提供可靠文字、语音和图解，再补充互动场景；
6. **保留现场**：追问前保存主题、子片段、时间进度、场景参数和最近操作；
7. **迁移为证据**：是否理解以新情境应用为主要依据，主观反馈单独记录；
8. **预设边界，动态讲解**：知识、误解和组件受控，讲解顺序和分支动态编排；
9. **儿童不贴标签**：儿童端不展示“误解类型”或家长介入结论；
10. **能力不伪装**：不确定、未覆盖、已降级和未保存必须明确表达。

## 6. 儿童端功能需求

### 6.1 首次使用与设置

**FR-C01 家长数据说明**

- 首次使用由家长确认测试 / 产品数据说明；
- 明确原始照片、原始语音、人脸、姓名、学校和班级默认不长期保存；
- 明确将保存的文字对话、讲解片段、场景状态、操作和理解结果；
- 提供孩子年级、教材版本、相关课外探索权限和历史保存设置。

### 6.2 儿童首页

**FR-C02 两个主要提问入口**

- “拍下不会的”；
- “问一个为什么”。

**FR-C03 知识星球**

- 位于两个提问入口下方；
- 展示少量经过预设和审核的知识解答；
- 点击后直接进入对应互动演示，不经过自由问题识别；
- 预设内容仍允许追问、修改场景和创建关联主题；
- 不呈现为传统课程货架。

**FR-C04 我的探索摘要**

- 首页最多展示 3 条最近问题卡；
- 右上角提供“全部探索记录”；
- 点击记录进入对应儿童探索记录。

### 6.3 拍照、语音与文字提问

**FR-C05 拍照提问**

- 只提交框选区域；
- 提交前提示检查姓名、学校和人脸；
- 拍照页面同时提供可选的语音和文字补充；
- 原始照片完成识别后按策略删除。

**FR-C06 语音 / 文字提问**

- 语音是主要入口，同时允许直接输入文字；
- 语音识别结果进入确认页；
- 文字修改后确认页显示最新文字，而非固定识别内容。

### 6.4 问题确认

**FR-C07 按来源差异化确认**

- 拍照来源显示“从照片中识别到的问题”和识别区域；
- 操作为“重新拍照、修改问题、就是这个问题”；
- 语音来源显示“我听到的是”；文字来源显示“你输入的问题是”；
- 语音和文字共用单一“修改问题”入口；
- 存在歧义时最多给出 3 个适龄学习目标候选。

### 6.5 诊断预测

**FR-C08 预测而非直接判错**

- 正式讲解前提出一个短预测；
- 选择后不立即显示对错；
- 预测结果影响后续讲解策略；
- 儿童端不显示“误解标签”；
- 置信度不足时继续澄清，不把猜测写成确定结论。

### 6.6 渐进式等待与降级

**FR-C09 渐进准备**

- 问题确认后开始规划，诊断预测期间并行准备开头内容；
- 开头优先采用语音、核心文字和可靠图解；
- 后续互动内容在开头播放时继续准备；
- 儿童端不展示模型、Token、队列或“片段生成中”。

**FR-C10 超时与失败**

- 有审核保底内容时自动降级；
- 后续互动失败时降级为图解、静态分步图或文字加语音；
- 无可用内容时保留问题和进度，提供“再试一次、换个问题、回首页”；
- 原型中的 5–8 秒与 15 秒仅为研究夹具，不是已实现 SLA。

### 6.7 核心探索

**FR-C11 两级讲解结构**

- 第一级为讲解主题，例如“琴弦振动”“真空中的声音”；
- 第二级为主题内子片段，例如“先看同一根弦”“用力拨改变了什么”“把发现说清楚”；
- 顶部切换讲解主题；
- 底部切换当前主题的子片段；
- 进度条必须明确标注当前子片段名称，只表示该子片段的播放进度。

**FR-C12 PPT 式讲解版式**

- 文案、比较条件、步骤、关键结论和可操作图解共同组成一张讲解幻灯片；
- 交互演示不得被当成与讲解文案脱离的独立 frame；
- 桌面 / 平板采用文案与图解并列；
- 手机采用同一内容的纵向排列；
- 只有具备可操作模型的子片段显示互动控制。

**FR-C13 播放与完成**

- 播放、暂停、切换和进度恢复作用于当前子片段；
- 语音、文字推进和视觉状态共享同一播放时间轴；
- 完成最后一个子片段后才显示“我看明白了，去试一题”；
- 非互动片段不保留空白操作区。

**FR-C14 桌面对话区**

- 平板 / 桌面右侧常驻对话；
- 未发生追问时显示“正在讲解……”和当前讲解内容；
- 追问后依次显示儿童问题、系统回答和关键结论；
- 不再提供独立“查看对话记录”入口。

**FR-C15 手机家教挂件与对话抽屉**

- 手机默认隐藏完整对话；
- 固定显示卡通家教“小知”挂件；
- 气泡提示“有不懂的，可以随时问我”；
- 点击挂件，从底部抽屉展开对话、语音追问和文字追问；
- 抽屉关闭后不影响讲解现场。

### 6.8 追问、主题分支与现场恢复

**FR-C16 语音和文字追问**

- 支持“语音追问”和文字输入；
- 开始追问时立即暂停当前子片段；
- 保存主题、子片段、时间进度、场景参数和最近操作；
- 显示识别 / 输入文字供儿童确认或修改。

**FR-C17 响应类型**

系统按优先级选择：

1. 修改原场景：速度、参数、标注、视角或并排比较；
2. 创建关联主题：需要新的对象或因果过程；
3. 图解 / 语音降级；
4. 澄清问题或说明能力边界。

**FR-C18 主题切换与恢复**

- 只有生成新的讲解和视觉内容时才创建新主题；
- 关联主题创建后，顶部显示多个主题供切换；
- 返回原主题时恢复被打断前的子片段、时间位置、参数和操作状态；
- 原型黄金分支为“如果没有空气呢？”。

### 6.9 迁移验证、反馈与完成

**FR-C19 迁移验证**

- 使用不同对象或情境验证同一概念；
- 首次答错给针对性提示，不直接显示答案；
- 支持重答；
- 保存“已理解、部分理解、仍需帮助 / 建议陪一陪”。

**FR-C20 主观讲解反馈**

- 选项为“讲明白了、还有一点不懂、没讲明白”；
- 可跳过；
- 后两项可补充“讲得太快、动画没看懂、想换一种讲法”等原因；
- 主观反馈和迁移结果分别保存，并标记一致 / 矛盾。

**FR-C21 完成页**

- 显示自动保存状态；
- 显示一句核心发现、实际操作反馈和追问产生的延伸发现；
- 提供“回首页”和“回看这次探索”；
- 不显示排名、星级、误解名称或家长介入建议。

### 6.10 我的探索

**FR-C22 探索记录**

- 每次完成自动形成一条记录；
- 展示标题、日期、主题数、追问数和儿童友好结果；
- 桌面 / 平板为列表与详情并排；
- 手机点击记录后在该条记录下方展开详情，再次点击收起；
- 每条样例显示与该问题对应的原有想法、关键操作和迁移结果。

**FR-C23 回放与继续**

- 回放通过事件、场景快照和内容版本重建，不保存视频；
- 可从可恢复节点创建新分支；
- 新分支不改写原历史；
- 新分支继承知识节点、对话摘要、误解假设、场景状态和内容版本。

## 7. 家长端功能需求

### 7.1 进入与隔离

**FR-P01 家长验证**

- 由儿童首页“家长工作台”进入；
- 使用四位 PIN 作为原型交互；
- 生产实现需补充更可靠的成人验证策略；
- 家长结论和敏感设置不出现在儿童模式。

### 7.2 今日

**FR-P02 三个可点击指标**

- 今天问了；
- 自己弄懂了；
- 建议陪一陪。

点击指标后进入探索记录，选择对应分类并锚定到相关记录区域。今日记录卡点击后进入“全部记录”，定位并展开该条记录。

### 7.3 探索记录

**FR-P03 分类**

- 分类为“全部记录、已理解、部分理解、建议陪一陪”；
- 展示每类数量；
- 每条记录同时显示学科 / 主题标签；
- 切换分类时收起已展开详情。

**FR-P04 原位展开详情**

- 默认仅显示分类后的记录列表；
- 点击记录后在该记录下方原位展开；
- 再次点击收起；
- 展开某条记录不改变当前分类；
- 详情包括结果、是否独立、儿童反馈、原有想法、视觉干预、迁移证据和家长建议。

**FR-P05 完整过程与删除**

- 详情可继续展开完整事件过程；
- 支持删除单次探索；
- 删除原始探索时级联删除后代分支及派生认知记录；
- 删除某一后续分支时保留原探索和其他分支。

### 7.4 近期学习画像

**FR-P06 研究项**

- 使用最近 14 天滚动窗口；
- 至少 5 次有效探索且覆盖 2 个概念后才形成归纳；
- 展示证据次数与“证据较充分 / 需要继续观察 / 近期趋势”；
- 不使用“视觉型学习者”等固定人格标签；
- 当前中保真阶段允许使用明确标注、与真实家庭隔离的演示档案；
- 是否进入 MVP 生产范围必须在家长价值测试和技术验证后决定。

### 7.5 设置

**FR-P07 设置范围**

- 孩子年级和教材版本；
- 相关课外探索权限；
- 探索历史保存开关；
- 保存期限；
- 原始照片和语音处理说明；
- 清空全部历史；
- 删除确认。

关闭历史保存前必须说明：当次仍可完成，但退出后无法回看或继续。

## 8. 内容范围与教学夹具

### 8.1 首批概念

1. 科学：振动、振幅、频率、响度、音调和介质；
2. 数学：平均分、分数表示及“分母越大分数越大”的误解。

声音黄金任务：

- 核心问题：用力拨琴弦，声音会更高吗？
- 比较边界：同一根弦，弦长、松紧和粗细保持不变；
- 原场景修改：慢放并保留“用力拨”的振幅；
- 关联主题：如果没有空气呢？
- 迁移题：同一音叉被更用力敲击时，音调是否改变。

### 8.2 知识原子最低要求

每个知识原子至少包含：

- 核心事实、适用边界、来源和审核状态；
- 年级、认知难度和前置知识；
- 常见误解及可观察信号；
- 推荐类比及失效边界；
- 可改变变量、因果关系和互动组件；
- 诊断问题、提示策略和迁移问题；
- 前置、因果、对比、类比、迁移和兴趣延伸关系；
- 2–3 条审核过的保底黄金路径。

## 9. 数据与状态模型

### 9.1 核心实体

- ChildProfile：年级、教材版本、授权设置；
- Exploration：起始问题、来源、创建时间、父探索、完成状态；
- Topic：主题标识、起始问题、父主题、知识节点、内容版本；
- Segment：顺序、文案、语音、视觉定义、时长、生成和降级状态；
- SceneState：组件、参数、相机 / 视角、标注、播放状态；
- InteractionEvent：选择、拖动、参数改变、播放控制和追问；
- Snapshot：主题、子片段、时间进度、场景参数和最近操作；
- LearningEvidence：预测、提示、迁移、独立完成和主观反馈；
- ContentVersion：知识、文案、场景和审核版本。

### 9.2 必须保存

- 文字化问题和对话顺序；
- 系统回答、讲解文稿和内容版本；
- 场景定义、关键快照和参数变化；
- 儿童预测、操作、提示和分支；
- 知识节点、误解假设、教学策略和迁移结果；
- 父子探索和父子主题关系；
- 创建、更新时间和删除状态。

### 9.3 默认不长期保存

- 原始照片；
- 原始语音；
- 人脸；
- 姓名、学校和班级。

## 10. 安全、隐私与合规

1. 拍照默认处理框选区域，并检测敏感信息；
2. 儿童数据保存基于家长明确授权和可管理期限；
3. 删除单次记录时同时清除对话、场景和派生认知数据；
4. 危险行为、成人内容、隐私索取和明显不适龄内容必须拒绝并引导；
5. 实验类内容必须显示安全边界；
6. 未覆盖或事实不确定时明确说明，不生成看似确定的动画结论；
7. 儿童模式不展示广告、付费弹窗或开放网络跳转；
8. 旧内容发生事实修订时保留修订标识，继续探索使用最新审核知识。

## 11. 响应式、可访问性与视觉约束

- 儿童主要点击目标不小于 48 px，家长控件不小于 44 px；
- 平板横屏：核心讲解与对话并排；
- 手机竖屏：讲解纵向排列，对话通过固定挂件和底部抽屉进入；
- 家长手机端：顶部横向导航固定为紧凑高度，内容区独立滚动；
- 所有选中、暂停、保存、失败和降级状态同时使用文字 / 符号，不只依赖颜色；
- 动画支持减少动态效果；
- 不使用仅 hover 才能发现的交互；
- 不在儿童端显示技术术语。

高保真阶段需补充但不改变信息架构：正式卡通角色、图标体系、排版尺度、语音录制反馈、抽屉动效、焦点状态、空状态、错误状态和减少动态效果样式。

## 12. 埋点与可观测事件

至少记录：

- 入口类型、拍摄 / 语音 / 文字开始和完成；
- 问题确认、修改和候选选择；
- 诊断预测选择；
- 主题和子片段开始、完成、切换、暂停、继续和进度调整；
- 互动组件参数变化；
- 语音 / 文字追问开始、确认和取消；
- 原场景修改、主题创建、主题切换和返回主线；
- 降级类型和失败原因；
- 迁移答案、提示、重答和最终结果；
- 主观讲解反馈；
- 保存、回放、从节点继续和分支创建；
- 家长指标点击、分类切换、记录展开和删除；
- 内容版本、知识来源和审核状态。

## 13. 非功能性候选要求

以下为技术验证目标，不是当前承诺：

- 80% 请求在 8 秒内出现可理解的首个讲解内容；
- 追问后 3 秒内给出确认反馈，8 秒内完成可见变化或明确降级；
- 场景恢复不丢失主题、子片段、时间位置和参数；
- 探索保存和回放具备幂等性；
- 严重知识错误为 0；
- 删除操作可审计且能够级联清理派生数据；
- 在目标微信版本、主流 iPad 和安卓平板上保持可用帧率与内存稳定。

具体测量方案、夹具和门槛见技术验证文档。

## 14. MVP 验收清单

### 14.1 儿童闭环

- [ ] 拍照、语音和文字三种问题输入可进入正确确认状态；
- [ ] 诊断预测会改变讲解策略；
- [ ] 主题、子片段和当前子片段进度层级清楚；
- [ ] PPT 式文案、图解和交互同步；
- [ ] 语音和文字追问均可暂停并保存现场；
- [ ] 支持至少一次原场景修改和一次关联主题创建；
- [ ] 可从关联主题返回原现场；
- [ ] 只有讲解完成后进入迁移题；
- [ ] 迁移、反馈、完成和自动保存可闭环；
- [ ] 历史可回放并从节点创建新分支。

### 14.2 家长闭环

- [ ] 家长入口只在儿童首页出现；
- [ ] 今日指标能定位到对应分类和记录；
- [ ] 探索记录按结果分类并有样例 / 真实数据；
- [ ] 点击记录后原位展开详情且不改变分类；
- [ ] 可查看关键证据和完整过程；
- [ ] 删除单次记录和清空历史有二次确认；
- [ ] 保存权限和期限可配置。

### 14.3 边界

- [ ] 原始照片和原始语音不进入长期记录；
- [ ] 生成失败存在可靠降级；
- [ ] 未审核内容不标记为可信生产内容；
- [ ] 研究用近期画像与真实儿童数据隔离并明确标注。

## 15. 风险与待决策项

### 15.1 主要风险

- 儿童语音、教材照片和问题意图识别不稳定；
- 误解诊断错误导致错误视觉干预；
- 动态场景延迟、成本或稳定性无法支撑；
- 场景状态无法可靠保存、恢复和回放；
- 互动有趣但迁移效果不优于固定内容；
- 家长能看懂报告但不形成付费价值；
- 儿童数据长期保存扩大隐私与安全责任；
- 微信运行环境限制音频、动画、内存或后台任务。

### 15.2 高保真前应确认

1. 正式品牌名和“小知”角色是否保留；
2. 微信小程序还是 H5 作为首个真实技术切片载体；
3. 手机与平板的首要设计基准尺寸；
4. 语音录制采用按住说话还是点击开始 / 结束；
5. 进度是否允许儿童拖动，还是首版只允许播放 / 暂停和片段切换；
6. 近期学习画像是否进入 MVP 开发，还是继续保留为研究演示；
7. 家长验证是否需要升级为微信账号 / 成人确认，而不是四位 PIN；
8. 首批生产知识点的审核人、来源格式和发布流程。
