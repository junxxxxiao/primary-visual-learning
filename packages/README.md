# 共享包工作区

本目录预留给从技术切片中提炼出的生产共享能力。不要提前复制临时代码。

候选包：

- `schemas/`：问题、讲解、场景、事件和证据契约；
- `scene-runtime/`：受控视觉组件与命令执行；
- `playback-engine/`：语音、文案、视觉和进度同步；
- `content/`：审核知识原子、误解和黄金路径；
- `event-store/`：事件、快照、回放和分支；
- `ui/`：跨应用共享的基础组件与 Token；
- `evaluation/`：技术与教学评测工具。

提取条件：

1. 对应技术切片已经通过；
2. 输入输出契约稳定；
3. 至少有一个真实应用消费者；
4. 已补充测试、版本策略和所有权说明。
