# TS-03 Round 5 中文人工审阅稿

## 文档说明

- 被审对象：DeepSeek 官方 API `official-full-round-5` 的 4 份冻结候选输出。
- 用途：供学科审核人与产品审核人检查讲解正确性、学段适配、渐进顺序、画面一致性和迁移质量。
- 整理原则：模型原有中文旁白、画面描述、静态降级和迁移题保持原意；英文知识 claim 翻译为中文以便阅读。
- 追溯原则：本稿不是新的模型输出。发生歧义时，以文末列出的原始响应文件及响应哈希为准。
- 证据限制：当前知识来源均为合成测试材料，只能支持技术切片审阅，不能视为真实教材或权威内容审核。

## 审核方法

每个案例分别检查以下七项，并在案例末尾填写结论：

1. 结论和推理是否正确，适用条件是否完整。
2. 引用的知识是否真正支持讲解中的关键结论。
3. 语言、术语和推理难度是否符合目标年级。
4. 分段是否循序渐进，旁白单独听是否完整。
5. 画面是否与旁白一致，是否存在误导或提前泄露后续任务。
6. 静态降级是否在没有动画时仍能讲清楚。
7. 迁移题是否真正改变对象、条件或推理方式，而不是简单换名称。

严重程度：`critical` 表示不能给儿童展示；`major` 表示必须修改后复审；`minor` 表示不影响核心理解但建议优化。

## 案例二：初中数学·完全平方与最大面积

**基本信息**

- 案例 ID：`middle_perfect_square`
- 目标学段：初中八年级数学
- 核心问题：为什么配方能证明靠墙围栏面积有最大值？
- 核心对象：靠墙围栏
- 响应哈希：`sha256:ebddb87297ebf5ba3d07e2caada64d93a8f7619dd2894462fbecc7ea14b6150d`

### 知识依据（中文翻译）

**claim：`perfect-square-identities`**

完全平方公式可以通过多项式乘法推导出来。

**claim：`complete-square-bound`**

利用实数平方的非负性，配方可以把最小值或最大值直接显现出来。

**claim：`fence-transfer`**

靠墙围栏问题可以建立面积模型，并通过配方求出最大值。

### 第 1 段：建立面积模型

**教学目标**

建立靠墙围栏的面积模型，引入变量并写出面积表达式。

**旁白原文**

> 我们用一段固定长度的篱笆靠墙围一个长方形区域。设垂直于墙的边长为 x，平行于墙的边长为 y。篱笆总长固定，所以 x + y + x = 总长，即 2x + y = 总长。面积 A = x × y。用总长表示 y，得到 A = x ×（总长 - 2x）。

**画面设计**

- 单主体展示靠墙长方形。
- 依次显示初始状态和变量标注。
- 画面术语：面积。
- 起始画面先静置 1 秒，再同时开始旁白和动画。

**静态降级**

1. 画出靠墙长方形，标注 x 和 y。
2. 写出 `2x + y = 总长`。
3. 写出 `A = x（总长 - 2x）`。

**引用**

- 关键事实：`fence-transfer`
- 前置知识：`math.algebra.multiply_binomials`

### 第 2 段：配方并证明最大值

**教学目标**

将面积表达式配成完全平方形式，展示如何得到最大值。

**旁白原文**

> 把 A = x（总长 - 2x）展开得 A = -2x² + 总长·x。提取 -2，配方：A = -2（x² -（总长/2）x）。加上并减去（总长/4）²，得到 A = -2[（x - 总长/4）² -（总长/4）²] = -2（x - 总长/4）² + 总长²/8。因为平方项非负，-2（x - 总长/4）² ≤ 0，所以 A ≤ 总长²/8。当 x = 总长/4 时取等号，面积最大。

**画面设计**

- 纵向逐步展示：展开、配方步骤、最终形式。
- 画面术语：完全平方、配方、非负、最大值。

**静态降级**

1. `A = -2x² + 总长·x`
2. `= -2（x² -（总长/2）x）`
3. `= -2[（x - 总长/4）² -（总长/4）²]`
4. `= -2（x - 总长/4）² + 总长²/8`
5. 因为 `（x - 总长/4）² ≥ 0`，所以 `-2（x - 总长/4）² ≤ 0`。
6. 因此 `A ≤ 总长²/8`，当 `x = 总长/4` 时取最大值。

**引用**

- `perfect-square-identities`
- `complete-square-bound`

### 迁移任务

**首次任务：固定周长花坛**

> 把固定周长的长方形面积配方，给出最大面积结论，并说明平方项为什么能证明它。

变化点：从靠墙三边围栏改为四边固定周长，约束条件发生变化，但仍使用配方。

**失败后任务：抛物线高度**

> 把二次式配成平方形式，判断最高点，并用平方项的符号解释原因。

变化点：从几何面积问题转为代数二次式，使用配方判断最高点。

## 案例四：初中声音配对·波形与听感

- 核心问题：驱动力增大但系统条件不变时，波形与听感怎样变化？

### 知识依据（中文翻译）

**claim：`force-amplitude-frequency`**

**claim：`wave-perception-map`**

**教学目标**

建立驱动力与振幅的关系。

**旁白原文**

> 当驱动力增大而系统条件不变时，振动幅度会明显增加，但频率基本保持不变。

**画面设计**

- 单主体展示示波器波形。
- 对比初始波形与增大驱动力后的波形。
- 画面术语：振幅、频率。
- 起始画面先静置 1 秒，再同时开始旁白和动画。

**静态降级**

1. 显示初始波形，标注振幅和频率。
2. 增大驱动力，波形振幅变大，频率不变。

**引用**

- 关键事实：`force-amplitude-frequency`
- 前置知识：`science.wave.amplitude`

### 第 2 段：波形与听感

**教学目标**

将波形变化与听感联系起来。

**旁白原文**

> 振幅增大使声音的响度变大，而频率不变意味着音调保持不变。

**画面设计**

- 左右对比小振幅和大振幅波形。
- 小振幅波形对应较小响度。
- 大振幅波形对应较大响度，两侧频率相同。

**静态降级**

**引用**
