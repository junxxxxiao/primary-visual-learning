# TS-04B 教学正确性、视觉场景布局契约与视觉缓存

> 状态：验证完成，有条件通过

> 基线：`origin/main` at `d447b5afe850a39873688777cde714a8483b3391`
>
> 对应验证文档：`docs/technical/2026-07-28-primary-visual-tutor-technical-validation-v3.md`

## 唯一验证问题

确定性的双学段场景能否在展示前通过同一接口验证关键教学与 ADR-0003 布局不变量，使全部已知相反关系和布局违规被拦截、失败场景不展示也不进入有效缓存，并使已验证缓存严格按版本失效？

## 不验证什么

- 不调用真实生成模型，不评估真实生成视觉质量、一次修复率、Token 或成本；这些属于 TS-04C；
- 不把声明式矩形当作真实 DOM、SVG、Canvas 或 OffscreenCanvas 测量结果；
- 不验证浏览器、微信 WebView、真实手机和平板的渲染差异；
- 不验证生产缓存后端、并发、淘汰、持久化或跨设备复用；
- 不验证端到端等待时间、真实音频时间轴或学习效果；
- 不修改公开 Demo，也不把本 spike 作为生产架构。

## 假设

如果教学事实、两端独立布局、画布安全内边界、非矩形内部安全区、关键状态、运动包络、可读尺寸和容器滚动指标都进入一个版本化验证接缝，那么确定性正负夹具应达到相反关系与已知布局违规拦截率 `100%`，失败展示与有效缓存写入均为 `0`，并且任一缓存身份字段变化都不能命中旧记录。

## 输入与输出契约

- `schemas/visual-scene.schema.json`：`visual-scene/1.0` 场景声明，包含教学事实、手机/平板独立构图、画布与局部安全区、全部必测状态、运动包络、可读性和容器 scroll/client 指标；
- `schemas/validation-result.schema.json`：`visual-scene-validation-result/1.0`，每个视口和状态输出 `pass/fail`、违规码、目标、实际值和期望值；
- `schemas/cache-record.schema.json`：仅允许 `validation_status=pass` 的缓存记录；
- `../shared/schemas/stage-timing.schema.json`：教学检查、每个视口/状态的布局检查、缓存读写和版本失效 span。

统一接缝是：

```python
validate_visual_scene(scene, viewport, state_id)
```

展示层和缓存层只消费整场景 admission 结果，不复制布局判定。

## 固定夹具

`fixtures/base-scenes.json` 包含两个完全合成的正夹具：

- 小学科学：更用力敲同一音叉时振幅增大、音调不变；
- 初中数学：用面积模型推导 `(a+b)^2=a^2+2ab+b^2`。

两者均分别声明手机竖向和平板横向构图，并覆盖起始、关键过程、最终、暂停、恢复、交互后、减少动态效果和静态降级 8 类状态。

`fixtures/cases.json` 通过可复核路径变异产生 15 个负夹具，覆盖：相反关系、模糊、超时、元素越界、非矩形内部安全区越界、隐藏裁切、仅中间运动轨迹越界、暂停、恢复、交互后、减少动态效果、视口切换、静态降级和不可读文字。

所有内容均为合成数据，不含真实儿童语音、照片、身份、对话或生产日志。

## 运行环境

- Python 3 标准库，无第三方依赖；
- 本轮环境和基线写入 `results/summary.json`；
- 不访问网络、模型或外部缓存，成本为 `0 CNY`。

## 运行方式

```bash
cd spikes/ts-04b-visual-scene-gate
python3 -m unittest discover -s tests -v
python3 run_validation.py
```

第二条命令重新生成：

- `results/summary.json`：门槛、逐案例摘要、版本失效结果和分阶段百分位；
- `results/audit.json`：全部视口/状态的机器可读判定；
- `results/timing.json`：符合共享 `stage-timing/1.0` 结构的原始 span。

## 决策

结论为**有条件通过**。确定性声明式门禁足以继续 TS-03，并可作为 TS-04C 的前置机器接口；在接入真实渲染测量适配器和真实模型产物前，不得把结果解释为动态生成视觉已可面向儿童展示。完整影响与限制见 `decisions.md`。

## 已知限制

- 当前边界数据来自夹具声明，尚未证明适配器能忠实读取浏览器计算样式、边界框和 scroll/client 指标；
- 固定双学段内容只证明统一契约可承载这两种形态，不证明跨学科覆盖；
- 教学检查使用受控事实的精确一致性，不替代 TS-02 来源核验或 TS-04C 人工学科评审；
- 没有验证自动重排、重新生成和多级静态降级选择；
- 时间样本来自单机标准库运行，不具有生产性能外推价值。
