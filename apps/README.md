# 应用工作区

本目录预留给通过技术切片后确认的真实应用。当前不锁定框架或创建空项目。

候选应用：

- `miniprogram/`：微信小程序儿童端与家长端；
- `web/`：H5 / 平板 Web 体验或运营预览；
- `api/`：问题理解、讲解规划、记录和家长数据 API；
- `admin/`：后续知识审核与内容运营工具。

进入条件：

1. TS-00 确认首发载体；
2. TS-03～TS-05 确认核心讲解、场景与恢复可行；
3. PRD 明确首个端到端垂直切片；
4. 数据、隐私和部署边界已评审；
5. 确认包管理器、运行时和仓库组织方式。

第一个应用初始化时，应同步更新根 README、运行命令、环境变量说明和 CI。
