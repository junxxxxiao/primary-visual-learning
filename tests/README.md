# 测试与评测

后续测试分为四层：

1. `unit/`：Schema、状态转换、场景命令和分类规则；
2. `integration/`：ASR、知识检索、讲解规划、TTS、场景和事件存储；
3. `e2e/`：儿童黄金路径、追问恢复、迁移、历史和家长记录；
4. `evaluation/`：知识正确性、误解候选、教学适切性、安全、延迟和成本。

测试数据规则：

- 默认使用合成或审核夹具；
- 真实儿童样本不进入 Git；
- 评测必须记录数据版本、评分标准和分母；
- 严重知识 / 安全错误单独报告，不被平均分掩盖；
- 固定夹具结果不得被描述为真实模型能力。

真实应用初始化后再创建具体测试框架和命令。
