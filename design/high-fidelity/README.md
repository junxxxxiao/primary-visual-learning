## 工作方式

- 本项目不使用 Figma；本目录中的本地 HTML、CSS、JavaScript、Token 和设计资产是高保真设计的可编辑交付源；
- 从仓库根目录运行 `python3 -m http.server 4173`，再打开 `/design/high-fidelity/` 下的页面进行评审；
- 全页面高保真支持 `?screen=lesson&viewport=phone` 形式的直达参数；`screen` 可选 `entry` 至 `result` 的 15 个命名页面及 `lesson-exit` 返回确认状态，`viewport` 可选 `tablet` 或 `phone`；
- 设计页应提供稳定的页面入口或查询参数，并记录基准视口、关键截图和人工验证结果；
- 设计预览不是生产应用代码，不进入 `apps/` 或 `packages/`，也不用于提前锁定生产框架；
- 共用视觉规则应逐步沉淀为本目录内的 Token 和可复用组件，避免页面之间复制后失去一致性；
- 至少验证平板和手机基准尺寸、键盘焦点、减少动态效果及浏览器控制台错误。

需求和交互仍以根目录 README 中的事实源优先级为准；本目录是已确认视觉方向和高保真交付的来源，不覆盖 PRD、原型或技术决策。

## 建议交付结构

```text
high-fidelity/
├── README.md
├── *.html           # 可直接运行的方向板和关键页面
├── tokens/           # 色彩、字体、间距、圆角、阴影、动效
├── components/       # 组件状态和开发映射
├── content/          # 审核文案、语音稿和知识点内容
├── assets/           # 经评审的角色、插画、图标和场景资产
└── exports/          # 临时导出，默认不进入 Git
```

目录在真正产生对应资产时再创建，避免空目录和占位文件。

## 必须覆盖的状态

- 拍照、语音和文字输入；
- 权限允许、拒绝和重新授权；
- 低置信度和问题修改；
- 首屏等待、渐进内容、降级和失败；
- 主题 / 子片段、播放、暂停和进度；
- 语音 / 文字追问、确认和取消；
- 手机家教挂件和对话抽屉；
- 保存成功、离线未保存和恢复失败；
- 儿童与家长记录展开、空状态和删除；
- 减少动态效果、焦点、禁用和错误状态。
