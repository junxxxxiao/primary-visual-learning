## 建议交付结构

```text
high-fidelity/
├── README.md
├── figma.md
├── tokens/           # 色彩、字体、间距、圆角、阴影、动效
├── components/       # 组件状态和开发映射
├── content/          # 审核文案、语音稿和知识点内容
├── assets/           # 经评审的角色、插画、图标和场景资产
└── exports/          # 临时导出，默认不进入 Git
```

目录在真正产生对应资产时再创建，避免空目录和占位文件。

## 必须覆盖的状态

- 拍照、语音和文字输入；
- 权限允许、拒绝和重新授权；
- 低置信度和问题修改；
- 首屏等待、渐进内容、降级和失败；
- 主题 / 子片段、播放、暂停和进度；
- 语音 / 文字追问、确认和取消；
- 手机家教挂件和对话抽屉；
- 保存成功、离线未保存和恢复失败；
- 儿童与家长记录展开、空状态和删除；
- 减少动态效果、焦点、禁用和错误状态。

## 设计完成定义

- [ ] 对应明确的 PRD 版本；
- [ ] 平板和手机基准尺寸已确认；
- [ ] 关键技术待定项已有决策或标记；
- [ ] 组件库与页面使用同一 Token；
- [ ] 正常、加载、失败、空和降级状态齐全；
- [ ] 文案经过产品与教学审核；
- [ ] 动效说明包含触发、持续时间、打断和减少动态效果；
- [ ] 设计资产来源和授权可追踪；
- [ ] 开发标注包含组件、状态、埋点和响应式规则。
