1. 最新 PRD；
2. 当前可点击原型；
3. 当前原型规范；
4. 技术验证文档及 P0 切片决策；
5. 家庭可用性测试结论；
6. 教师审核内容和文案包；
7. 品牌、角色和目标设备 Brief。
